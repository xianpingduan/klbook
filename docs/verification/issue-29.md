## 已实现行为

- 原根地址进入 `/learn`；学习端三个 Tab 对应首页、收集、我的；独立 `/admin` 及其侧栏页面可直达、刷新、前进/后退。
- 初始化、登录、账号恢复和恢复码保存确认保留原访问目标；管理端使用真实家长验证，刷新后重新验证，授权有效期仍为五分钟。
- 管理概览组合已有接口，使用已收集/草稿的真实总数、启用来源数、有效设备数；部分请求失败单独显示不可用及重试。
- 新入口接入原有题目列表、收集、原始页、更正、来源和设备能力。来源表单在管理到期及服务端拒绝后保留，同一家庭重新验证可继续。旧会话失效后卸载旧工作区。
- 保留协议、主机、端口与数据/凭据/暂存结构；未知 API、附件和静态资源不会回退为 HTML 成功响应。

## 测试边界与证据

使用公开接口、完整浏览器流程、隔离 SQLite 数据库与真实图片，不接触实际家庭资料。

- 类型检查和生产构建通过。
- 18 个 API 用例通过，包含新增页面路由及资源错误边界。
- Edge、Firefox、WebKit 各 12 个浏览器用例通过，共 36 项。
- 新增浏览器场景：管理地址登录和历史导航、直接管理入口初始化与账号恢复、52 道已收集题与 1 份草稿的统计、停用来源和撤销设备排除、部分读取失败重试、到期/真实服务端撤销后重新验证及表单续接。
- 390、820、1440 CSS 像素视口检查了两端外框，无页面横向溢出；学习 Tab 触控高度至少 48 CSS 像素。截图由浏览器用例生成。
- 初次完整回归在沙箱内启动 Firefox 时停顿；同一用例在正常本机权限下通过后，仅重跑受影响的 Firefox/WebKit 部分。该环境问题不计为通过结果。
