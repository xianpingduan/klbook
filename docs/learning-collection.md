# 学习端收集与续接（#30、#9、#34）

实施依据：[任务 #30](https://github.com/xianpingduan/klbook/issues/30)、[独立布局规格](spec-ui-separation.md)。

## 固定操作路径

- **首页**：固定鼓励语及已收集题目；超过一页继续加载。空库提示使用底部收集入口。
- **收集**：触控设备提供拍照、相册；电脑提供一个选图入口。按输入能力而非屏幕宽度选择入口，不改变学习者身份。支持原有格式与批次限制。
- **我的**：真实连接检查、资料库身份、家长管理与退出。
- **整理题目**：先框题，再确认学科。换图靠近图片，整页与多区域工具折叠；来源、页码、题号、阶段与备注放在“补充信息”，跨页、阅读材料和答案在“更多整理”。每步只有一个固定主操作。详情统一从“编辑资料”进入，原始页按需展开；有批次则继续下一张，没有则完成并回首页。

## 材料与失败状态

收集页展示待处理批次和已保留的草稿；设备离线时只显示本机实际保留的资料，并提示当前无法获取家庭电脑的最新内容。设备暂存独立于服务器列表读取，服务器失败不隐藏本机材料，也不把读取失败显示成空库。相机取消或不返回照片时提示使用相册；网页不能可靠区分系统相机未打开和权限被拒绝。

沿用现有 `CaptureCache` 的批次结构及资料库/账号作用域。先持久保存原图片和操作标识，再上传；上传响应丢失或暂存进度写入失败时，用同一个操作标识重试。取消本机材料只移除本机批次项，已接收的服务器草稿仍保留。未确认的上传不标成已同步。

列表读取和写入使用各自的忙碌状态；上传、保存、更正、取消后更新列表。题目打开时重新读取最新修订。旧工作区卸载后，不再继续发起上传或处理会话失效回调；新会话从所属资料库的暂存作用域读取。

## 离开保护

学习端普通题目编辑在每次修改后同步写入本机编辑日志，再在后台同步草稿。返回、后退或刷新不需要另点保存；只有“保存到错题集”才完成收集。已收集题目的未提交更正只在本机保留，以“保存修改”确认。存储失败会提示并恢复离开保护，不宣称保存成功。

管理端、独立阅读原文及答案编辑器仍使用显式保存和离开保护；题目编辑与这些子流程衔接时保留本机字段并核对修订，避免自己补充答案后覆盖正在编辑的题干。

离线重开需先在可信 HTTPS（电脑本机可使用 localhost）在线准备页面，并保持有效的设备登录。“我的”显示页面准备状态。图片与必要资料必须实际缓存才能访问；清理浏览器站点数据会移除设备暂存。恢复连接后重新打开或刷新应用，会先验证资料库及账号，再用原请求标识补传图片和编辑；两台设备的版本冲突须由用户核对。

实现、自动化证据与待做的真机项目见 [#9/#34 验证记录](verification/issue-9-34.md)。

## 范围

学习端和后台复用编辑、原图、批次及保存逻辑，避免出现两套持久化行为。后台表格、同页看图编辑与来源管理的实现见 [#31 说明](admin-materials.md)，设备与账号界面归 #32。验证和新版真机清单见[验证记录](verification/issue-30.md)。
