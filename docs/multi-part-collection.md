# 一页多题与跨页题目

对应任务 [#5](https://github.com/xianpingduan/klbook/issues/5)，沿用独立学习端与家长管理端。

## 操作方式

1. 拍照或选图后，按原流程框住一道题、确认学科并保存。
2. 这页还有其他题时，在详情选择“从此原始页再收集一道”，重新框选并单独确认学科。打开此入口不会创建另一条记录，只有明确保存才生成新题。题目分别保留自己的学科、边框、来源和备注，同页原图共用。
3. 一道题跨页时，在编辑中使用“追加跨页图片”。每次追加一张并框选题目区，保存后可继续追加；与普通图片相同，支持 JPEG、PNG、静态 WebP，每张不超过 15 MB / 4000 万像素。
4. 调整范围时点击题目区编号，可以重画、精确调整、清除、向前/向后移动或移除。保留至少一个题目区；同一原始页也可“在本页补充题目区”，这仍属于同一道题。每题最多 50 个题目区。
5. 学习端详情按顺序显示所有题目区，完整原始页按首次引用顺序展示，同页不重复展示原图。跨页题可选择其中某一原始页，再从该页收集另一道独立题。

“已收集”仍要求学科及每个题目区均已确认。草稿允许暂未框选；移除区域不会删除原始页，也不会更改其他题目的边框。页面顺序更正保留题目身份及原收集时间。

## 保存与材料保护

同页新题使用稳定操作标识，保存响应丢失后重试不会多建题目。跨页图片上传只保存原始页，不额外产生另一道草稿；最后随题目保存提交有序引用。

追加图片先保留在当前服务地址、家庭账号及题目所属的设备暂存中。失败时保留图片及操作标识，重新打开原题的编辑页面可继续追加；服务器已收到的图片通过相同操作重用。图片成功上传后，题目引用保存成功才清除相应追加暂存。

未保存边框、排序和其他表单继续使用现有离开保护。刷新/关闭仅恢复已持久保存的题目及暂存图片，不承诺所有未提交范围都已落盘；重开可能需要重新框选。明确放弃表单不会删除未处理的追加材料，可回到原题继续或取消追加。新建的同页题先保存，再追加跨页图片。

管理请求携带原家长授权，到期或被拒绝后暂停写入；日常学习会话仍可整理题目。服务端检查页面所属资料库、每个区域范围、重复标识、修订及实际附件后，在同一事务中提交完整关联。文件不可读、并发冲突或保存失败不能发布半道跨页题。

## 数据与接口兼容

数据库追加 `questionParts`，保存题目内稳定区域 ID、原始页引用、顺序和范围；旧题自动迁移为一个题目区。追加图片使用独立操作记录，不改动原图片字节或旧题身份。

`Question.parts` 返回有序题目区。原 `originalPage` / `region` 继续表示首个题目区，旧客户端省略 `parts` 更正时保留其他题目区；修订冲突仍拒绝覆盖。已有上传、修改操作的重试协议保持兼容。

- `POST /api/v1/collection/pages/:id/questions`：从已有原始页明确创建另一道题。
- `POST /api/v1/collection/pages`：通过稳定操作 ID 上传追加原始页。
- `PUT /api/v1/collection/questions/:id`：可附加有序 `parts`，一次保存所有边框、关联和排序。

这项功能提供手动选择；识别候选题、共享阅读材料及答案关联分别由后续任务承接。验证证据见 [#5 验证记录](verification/issue-5.md)。
