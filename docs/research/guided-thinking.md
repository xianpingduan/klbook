# 引导思考与跨设备载体：能力边界

核实日期：2026-09-15。范围：面向四年级孩子，覆盖语文、数学、英语、科学；先给自家孩子用，早期侧重习惯培养。

## 结论

**基础引导不必须依赖外部 AI；针对具体照片题意的自动引导，可以接入外部模型或题库。** 二者应该分开设计。下面的产品安排是提案，尚未确定模型供应商、费用预算或部署方案。

## 哪些可以由 App 自己完成

以下是工程设计判断：App 可以按孩子选的学科、卡点与操作，展示事先编写的提示；无需先识别照片内容。

| 场景 | 内置提示示例 |
| --- | --- |
| 通用总结 | “你做到哪一步卡住了？”“下次准备怎么检查？” |
| 数学 | “题目要你求什么？”“哪些条件能用上？” |
| 语文 | “你的回答能在原文哪一句找到依据？” |
| 英语 | “你能先找出看懂的词吗？” |
| 科学 | “你观察到什么？”“哪条证据支持你的判断？” |

这类提示有固定适用范围，不能声称已经看懂孩子刚拍的题。保存照片、记录一句总结、安排重做、标记待求助与记录进步，也可按产品规则实现。

## 哪些需要额外能力

阿里云百炼官方说明视觉模型支持单图或多图输入、视觉问答、文字与公式提取，并展示学科题解用途。这证明了可接入的技术能力；不能据此保证四年级四科题目的正确率或教学效果。[阿里云：图像与视频理解](https://help.aliyun.com/zh/model-studio/vision)

| 可选路线 | 适用意图 | 需要区分的边界 |
| --- | --- | --- |
| 视觉模型直接看图 | 结合照片与孩子的回答，生成下一步提示或讲解 | 必须验证读题、推理及措辞是否适合孩子 |
| OCR ＋ 模型 | 先提取题干，允许校正，再生成提示 | OCR 是识字、识公式；教学引导是另一个步骤；图形题还可能需要保留图片 |
| 题库或人工模板 | 为已匹配的知识点提供提示、讲解、变化题 | 需要维护内容与匹配规则；不能假定任意照片均能匹配 |

后两行是架构选择，不是已经选定的服务。视觉模型本身可处理图文输入，因此并非必须再购买一个独立 OCR 服务。

Google 官方同样提供图片与文字联合输入；文档要求图片清晰、方向正确，指出更高细节分辨率会增加令牌消耗与延迟，并提醒生成结果可能不准确。[Google：图像理解](https://ai.google.dev/gemini-api/docs/image-understanding)

**据此提出的产品处理：** 保留原图；遇到模糊或条件不全时请孩子补拍或确认；动态提示与变化题按待验证内容处理。一次重做或一次 AI 判断不直接等于“已掌握”。

## 适合首版的提案

1. 先完成“拍照收集 → 孩子说一句卡点或错因 → 回来重做 → 记录变化”的流程，内置简短的分学科提示。
2. 增设可选的“帮我想下一步”：若接入 AI，优先给一个小提示，再根据孩子反馈继续；仍不明白就加入待求助，由家长查看。
3. AI 未配置、超时或内容存疑时，仍可保存题目、记录总结、重做与求助。
4. 变化题先作为孩子主动选择的挑战；用真实错题样本核对题干、答案和难度后，再扩大自动生成范围。

用户已补充：纸质材料同时包含批改和答案。因此优先把已有纸质答案与题目关联，保留其来源；AI 可以辅助提示与讲解，生成答案不能自动视为标准答案。

这些是待验证的设计建议，不是已证明有效的学习干预。供应商、模型版本、费用、部署地域和接入时间仍未决定。

## 手机、平板、电脑的产品载体

**可考虑响应式网页，按需增加 PWA 安装能力。** 响应式布局调整不同屏幕上的内容；还应兼顾触摸、笔、鼠标和键盘，并在实际设备与浏览器上检查体验。[MDN：PWA 最佳实践](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Best_practices)

“浏览器可打开”和“能添加到桌面并以独立窗口启动”是不同能力。PWA 的安装入口与支持程度随平台、浏览器而异；不支持安装时仍可作为普通网页使用。[MDN：让 PWA 可以安装](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

架构判断：网页适配多设备并不会自动带来错题数据同步。跨设备同步仍需统一的数据存储与访问身份。研究时用户曾接受云端保存，后续已改为本地电脑保存资料、所需中间件本地安装，并在 Q39 确认家庭局域网访问；当前方案见[本地部署与存储](../local-deployment.md)。这项依赖与“是否接入 AI 引导”应分别决策。
