## 自动化验证

测试使用隔离的真实本地数据库、图片和公开接口，不操作家庭实际资料。

- 类型检查、生产构建通过；18 个 API 用例通过。
- Edge、Firefox、WebKit 各 19 个浏览器场景，共 57 项均取得通过结果。首次完整回归 48 通过、9 失败；修正框题视口、WebKit 保存离开时序及测试选图等待后，最终受影响的 36 项全部通过，未受影响的 21 项沿用该次完整回归结果。最终共享范围校验改动后，6 个收集 API 用例另行复测通过。
- 失败注入中，WebKit 的拦截转发无法取得 File 对象的请求体，现用实际选择的测试图片字节转发，并断言服务器确实接收成功后才丢弃响应，避免把无效上传当作已接收。截图与执行记录保存在 `.scratch/issue-30/full-suite/`、`final-affected/` 及 `test-results/`。
- 新增流程覆盖：三个 Tab 职责与唯一入口；分步收集及跨会话原图/字段读取；浏览器后退、继续编辑、保存失败后重试及放弃；已收集题校验失败与保存后切端；51 道已收集题及 51 份草稿的分页；服务器列表不可用时读回本机图片；取消不删除已接收草稿；资料库变化后不混入旧家庭批次。
- 保留并更新原有批量三张、取消一张、刷新续传、方向校正、鼠标/触控框题、实际服务停止与重启、响应丢失、磁盘/IndexedDB 故障、来源管理等流程。
- 检查 390、820、1440 CSS 像素视口无页面横向溢出、主要按钮至少 48 CSS 像素，以及键盘访问与缩短视口后滚动至保存按钮。浏览器视口检查不代表真实软键盘或系统相机测试。

## Spec
