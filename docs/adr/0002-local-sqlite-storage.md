# 单家庭资料库采用 SQLite 与本地附件

首版是一台 Windows 电脑服务一个家庭、少量设备通过 API 收集资料，现有环境没有确认可复用的 PostgreSQL 服务，因此采用 SQLite 与后端管理的本地附件目录，减少独立数据库的安装维护。此前 PostgreSQL 仅是候选建议；本决定接受 SQLite 单写者的限制，以短事务、修订号和稳定操作 ID 处理并发与重试，数据库不放在网络共享目录。

备份仍须覆盖一致数据库快照及其附件，而不是仅复制数据库主文件；若未来需要多服务器或大量并发写入，再评估 PostgreSQL 和真实数据迁移成本。环境、替代方案和验证记录见 [基础技术选型](../technical-selection.md)。
