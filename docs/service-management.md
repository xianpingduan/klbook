# 后台服务管理

用户已明确要求：图片识别服务、语音转写服务、AI 服务可以在后台管理和启用。三类能力分别配置、独立启停；当前仍为设计文档，尚未实现或接通外部服务。

本文是服务管理的设计细化，收集版范围见 [collection-v1.md](collection-v1.md)。首批家庭使用场景下，由具有管理权限的家长操作。

当前部署要求：应用后端及所需中间件在本地电脑安装运行，服务配置和学习资料保存于本地。图片识别、语音转写和 AI 学习仍沿用独立配置与启停规则；选择外部供应商时，由本地后端发送本次调用所需的图片、录音或文字，结果保存回本地。存储本地化不表示这三类模型已经在本机运行；如使用本地模型，须提供适配接口并另行验证能力。

客户端另设“服务地址”，用于选择连接哪个错题集后端，规则见[本地部署与存储](local-deployment.md)。这里的供应商接口、模型和凭据仍由目标后端的管理员配置；修改客户端地址不修改这些供应商配置，也不使客户端直接调用供应商。

## 管理对象

| 服务类别 | 在本应用中的用途 | 停用或不可用时的处理 |
| --- | --- | --- |
| 图片识别服务 | 提取题干文字和公式，提供候选题目边框、学科和题号建议 | 仍可拍照、从相册导入、手动框题并保存；已有识别结果继续可查看 |
| 语音转写服务 | 将孩子的语音备注、错因总结或后续解题思路录音转成可修改文字 | 支持录音的页面仍可保存原录音，也可手动输入文字；转写可待之后主动重试 |
| AI 学习服务 | 提供学习提示、讲解和拓展内容 | 对应 AI 学习入口暂不可用；图片收集、查看和已保存资料仍可使用 |

图片识别本身可以由视觉 AI 提供，但它与 AI 学习服务是两类独立能力。停用 AI 学习服务不会连带停用图片识别；同一家供应商可被多类能力使用，每一类仍保持自己的配置与开关。

## 配置与操作

每类服务提供独立配置，设计包含以下项目；具体字段按所选供应商适配。

| 项目 | 内容 |
| --- | --- |
| 配置名称 | 便于管理员辨认用途的名称 |
| 供应商 | 实际承载该能力的服务商 |
| 接口地址与地域 | 服务端使用的接入地址、所需地域配置 |
| 模型或服务标识 | 使用的模型、识别接口或转写服务 |
| 访问凭据 | API 密钥或供应商要求的凭据，支持更新替换 |
| 启停开关 | 该类能力是否允许发起新业务调用 |
| 调用限制 | 超时时间、有限重试及调用额度等必要限制 |

管理员可以保存、修改配置，测试连接或功能，启用、停用，并查看运行状态。保存配置与启用分开处理；保存配置本身不触发识别、转写或 AI 生成。

测试应明确展示测试对象、成功或失败、耗时和可理解的错误摘要。测试若产生外部调用，需计入服务用量；凭据不能出现在测试输出中。

更换供应商时需要适配其实际接口和支持的能力，不能仅通过填写任意地址就宣称支持所有供应商。

## 状态和开关规则

- 管理员的启用意愿与服务运行状态分别记录：服务可能未配置、已停用、已启用且可用，或已启用但发生调用异常。
- 启用前校验必要配置；未配置完整的服务不能被前台当作可用能力。
- 服务端在每次发起新调用前检查开关和配置，防止旧页面在停用后继续提交新任务。
- 停用后停止新业务调用和自动重试；已经发出的请求如实显示处理状态，已保存的图片、录音和结果继续保留。
- 重新启用后按用户的新操作使用服务；历史图片、录音或失败任务需要主动选择重试，避免启用时自动扫描全部资料。
- 前台根据已实现的功能和当前可用能力提供入口；启用外部服务不会自动产生尚未实现的学习页面。

## 管理权限与凭据

- 服务管理属于后台管理权限，孩子的日常收集页面不显示密钥和供应商配置。
- 外部服务通过服务端调用。密钥保存在服务端受保护配置中，管理界面仅显示已配置状态或掩码，允许替换，不返回已有密钥明文。
- 管理权限在服务端校验，不能仅依赖隐藏按钮。
- 配置变更和启停记录操作人、时间和操作类型；调用记录保留服务类别、状态、耗时、用量与错误摘要，避免记录凭据。

## 用量与费用

- 分别统计图片识别、语音转写、AI 学习服务的调用量和失败情况。
- 在供应商返回相应用量时记录 Token、音频时长或计费次数，按配置价格估算费用，并标明估算性质。
- 三类能力及实际运行服务继续受每月 50 元试用预算约束；首版以本地部署重新测算，不采用此前云托管套餐作为必需开支。接入时再确定额度分配和告警阈值，本地硬件与电耗另行记录。
- 达到应用设置的调用额度时停止新增付费业务请求，保留手动收集和查看能力。最终费用仍需结合供应商实际计费核对。

## 与当前收集版的关系

Q36 已确认：第一版后台提供三类服务的配置、测试和启停，孩子端先使用图片识别完成核心收集流程。语音总结、AI 讲解和拓展等孩子端页面在后续阶段实现；后台启用服务不会改变这一交付范围。

服务未配置时默认不发起相应外部请求。具体供应商、实际模型、生产凭据、初始启用状态和额度尚待接入时确定；当前没有注册、购买或启用任何真实外部服务。

## 验收场景

1. 三类服务可以分别配置和启停；停用其中一类不改变另外两类的开关。
2. 停用 AI 学习服务后，已启用的图片识别仍能被调用。
3. 图片识别停用、未配置或失败时，拍照和相册导入仍可通过手动框题完成保存。
4. 语音转写停用时，已实现的录音功能仍能保存原录音，既有转写内容可查看。
5. 普通孩子页面不能读取或修改服务配置，前端响应与运行日志中不会包含访问密钥。
6. 服务停用后，使用停用前打开的页面也不能继续发起新的该类业务调用。
7. 保存配置或重新启用服务，不会自动处理历史资料；主动测试和重试计入用量。
8. 服务调用失败时后台能定位到对应服务的状态与错误摘要，前台保留当前已保存的收集内容。
