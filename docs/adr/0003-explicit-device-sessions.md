# 可变服务地址使用显式设备会话

客户端需要保留固定网页来源下的暂存，并能连接不同局域网主机或 IP，而 Safari 的第三方 Cookie 限制使跨站 Cookie 无法作为统一登录前提。因此 API 使用可撤销的不透明设备令牌，管理权限另行短期验证；接受持久设备凭据可被同源脚本读取的代价，并通过脚本来源限制、输出安全、令牌摘要存储和撤销机制约束风险。

新地址必须先无旧凭据探测，再重新认证并核对资料库和账号，不能根据未认证的相同 UUID 自动复用旧令牌。浏览器事实与受保护附件处理见 [局域网研究](../research/browser-and-lan-constraints.md)，实施边界见 [技术选型](../technical-selection.md)。

后续加入 Capacitor 时仍复用设备会话协议；上述持久凭据存储取舍针对网页，移动 App 采用原生安全存储适配，见 [ADR 0004](0004-capacitor-mobile-delivery.md)。
