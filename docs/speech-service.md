# 语音转写服务管理

任务：[GitHub #15](https://github.com/xianpingduan/klbook/issues/15)。入口：`/admin/services/speech`，需要家庭登录与有效家长验证。

## 已实现范围

后台独立配置、启停及主动上传测试音频，查看转写文字、耗时、音频计量、尝试次数、估算费用与操作审计。孩子端录音、语音总结、解题思路仍由后续任务承接。图片识别保持独立；AI 学习的实际接入尚未实现。

## 供应商和输入

使用讯飞 **语音听写（流式版）** 标准接口 `wss://iat-api.xfyun.cn/v2/iat`，固定官方端点，不接受任意供应商 URL。中文普通话与英文分别选择，普通话可包含简单英文。固定 `domain=iat`，不主动开通动态修正、行业或方言等附加能力；若供应商返回分段修正，按序号和替换范围合并。

接口没有地区或模型 ID 参数，页面展示具体产品，不能据此声称特定物理机房。凭据需要该应用的 APPID、APIKey、APISecret，以及单独开通的语音听写权限；OCR 权限不能代替语音权限，也不自动复制 OCR 的凭据。

本次后台测试接受 **WAV 容器内的 16 位 PCM、单声道、8 kHz 或 16 kHz**，不超过 60 秒和 2 MiB。服务端检查 RIFF 长度、格式和音频块，不靠扩展名判定格式；忽略合法的附加元数据。发送时剥离 WAV 容器，以约 40 ms 音频一帧发送 Base64 PCM，并发送结束帧。不支持的 MP3、M4A、压缩 WAV 或其他采样率会明确拒绝，不静默改写输入。

选择文件只在当前页面试听；点击“发送所选音频并测试”后才上传和调用讯飞。文件不会进入错题集，服务器仅在处理与重试期间持有音频内存；数据库持久保存文字与测试计量，不保存测试音频或原始供应商报文。刷新后需重新选择文件才能发起另一次测试。

实现依据：2026-10-19 查阅的[讯飞官方接口文档](https://www.xfyun.cn/doc/asr/voicedictation/API.html)与[服务开通页](https://www.xfyun.cn/services/voicedictation)。音频限制、鉴权、分帧、结果修正与错误码依官方接口实现，真实账号效果仍需实测。

## 调用与限额

- 默认停用，保存配置不产生外部调用；启用也不补发历史材料。语音测试必须先启用，与 OCR 管理页面允许停用时主动测试的约定不同：#15 要求新语音请求及重试受自身开关控制。
- 默认不自动重试，可设置 0～2 次；每次请求超时为 5～120 秒，默认 90 秒，包含建立连接、流式发送和等待结果。应大于音频时长。
- 每个新尝试前重新检查家长权限、配置版本、启停状态、次数和预算；修改配置会停止尚未发送的尝试。一次已发出的请求不会因停用而改写成“已取消”，正常返回仍保存实际成功或错误。
- 超时、断连和进程停止标明结果不确定，保留估算费用。重启把遗留运行记录标为中断，不自动补发。供应商提前结束且仍有音频未发送时，不记为完整成功。
- 使用请求 ID、配置修订号和音频摘要识别同一次上传重放；响应丢失后重试同一请求不重复调用。更换音频或版本不能沿用原请求 ID。
- 北京时间自然月统计独立的尝试次数、每次尝试的输入音频时长合计和估算费用。不是实际发送时长或供应商账单。失败及自动重试计入尝试次数，明确拒绝不预留费用，成功和不确定请求预留估算费用。
- 每次估算单价由家长按实际套餐填写，默认 0 表示未设置付费估算或使用免费包，不能证明服务免费；配额余额和有效期不自动同步。全能力汇总由 #17 实施。

## 权限和凭据

沿用家庭会话与家长短期授权。所有管理接口先鉴权再处理请求。配置采用修订号与操作 ID，避免多页面覆盖或重复保存；操作审计仅记操作者、时间和操作类型。

凭据用 AES-256-GCM 加密，语音和 OCR 使用不同的附加认证数据，共用本安装的 `service-credentials.key`。页面仅显示已配置／是否可读取，三个凭据字段均不回填。离开管理或授权到期清空未保存凭据。已有任一能力密文时，丢失密钥不能通过配置另一能力重新生成密钥覆盖原关系；仍可停用，恢复配套密钥后再调用。

签名 URL、密钥、供应商原始错误不写调用记录或返回客户端；握手失败提示检查网络、权限、凭据与系统时间，不把所有连接错误误判成单一鉴权原因。完整安装备份必须包含一致数据库、附件及配套密钥。学习资料导出不应包含这些凭据。

## 真实服务验收

1. 在讯飞控制台创建／选择应用，开通“语音听写（流式版）”及需要的语种，核对试用额度、有效期和 IP 白名单。
2. 家长进入“语音转写服务”，在本机页面填写三项凭据，设置次数、预算和实际估算单价，勾选启用后保存。不要把密钥发到聊天或议题。
3. 选择一段 5～10 秒、符合上述格式的清晰语音，先试听，再主动发送。可参考官方文档的音频样例；PCM 原始样例需封装成正确的 WAV，不能只改扩展名。
4. 核对转写文字、音频时长和次数；刷新并重新验证后应仍有文字记录。再停用，确认不能发送新测试，原记录保留，图片识别配置不变。
5. 记录日期、产品、语言、音频格式／时长、实际结果、耗时及控制台用量差异，勿记录密钥。未做真实样例前不关闭 #15。

## API

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/admin/speech` | 安全配置投影、本月计量、最近 20 次测试、最近 30 条操作审计 |
| `PUT /api/v1/admin/speech` | JSON 配置、可选新凭据、`operationId`、`expectedRevision`；不调用供应商 |
| `PUT /api/v1/admin/speech/tests/:id?revision=N` | `audio/wav` 二进制音频；显式提交异步测试，返回 202；配置接口读取进度 |

正常家庭资料库通过追加迁移创建语音专用表，不重建旧表或账号。OCR 的历史表与接口保持兼容。
