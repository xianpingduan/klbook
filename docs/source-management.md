# 来源选择与管理

对应用户补充需求 [#27](https://github.com/xianpingduan/klbook/issues/27)。来源是选填归档项，供孩子收集或补充错题时从列表选择。家长在“家长管理 → 来源管理”新增、改名、停用或重新启用。

## 使用规则

- 初始来源为课堂作业、练习册、试卷、其他。可以新增具体材料名称，例如“四年级数学练习册”。名称两端空白去除后须为 1～200 个字符，拒绝同名项（英文字母大小写不区分）。
- 收集页面可选择来源或“暂不填写”，不增加保存必填条件。普通设备会话只能读取可用来源，管理接口须同时具备该设备有效的家长管理授权。
- 来源以稳定 ID 关联题目。改名统一更新旧题的显示名称，不修改题目的收集时间、修订号、原始图片或其他字段。
- 停用后不供其他题目新增选择，已关联题目仍显示该来源、可保留该来源修改其他内容，也可清空或改选。重新启用后恢复可选。
- 当前通过停用处理不再使用的来源，没有物理删除、层级和排序功能。按来源筛选在 #8 等检索任务落实。

## 数据与升级

迁移 5 新增 `sources`、`sourceOperations` 与题目 `sourceId` 外键。来源属于当前后端的单家庭资料库，随机 UUID 在重启和跨设备访问时保持不变；预置来源也存为普通可管理记录。

升级时先建立预置来源，再把已有非空文字来源加入列表并关联原题；同名项复用。空来源保持 `sourceId=null`。旧的来源文本列保留用于兼容，读取时优先使用关联来源的当前名称。迁移在同一数据库事务内完成，不修改附件，也不更改既有账号和会话。

来源管理的 `revision` 与题目修订分别维护。新来源的期望修订为 0，创建后为 1，每次新管理修改加 1。旧修订写入返回 409；操作标识按家庭、账号和操作 UUID 唯一保存，相同操作同内容重试返回当前记录，不重复新增或递增修订。

## 公开接口

| 方法与路径 | 权限与行为 |
| --- | --- |
| `GET /api/v1/collection/sources` | 普通登录；返回启用来源 |
| `GET /api/v1/admin/sources` | 家长授权；返回全部来源及停用状态 |
| `PUT /api/v1/admin/sources/:id` | 家长授权；客户端创建 UUID，提交 `operationId, expectedRevision, name, active` |

来源返回 `id, name, active, revision`。题目读取增加 `sourceId`，同时保留 `source` 显示名称；新版题目写入提交 `sourceId` 或 null。来源停用校验与题目修订检查在发布事务中执行，避免另一设备停用后被旧下拉列表继续关联。

旧客户端可暂时使用单独的 `source` 文本字段，保留已有来源、选择已有启用来源或清空；不能通过旧接口偷偷新增来源。未知名称返回提示要求刷新并使用列表。不能同时提交 `source` 与 `sourceId`。旧操作的请求摘要保持兼容；重试先匹配已提交操作，再检查最新来源状态。
