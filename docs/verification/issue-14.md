## 已完成的定向流程

公开 HTTP API 5 项流程通过：停用时保存、启用不扫旧页、主动识别与跨设备读取；新上传只识别一次、候选确认保存与原结果追溯；业务启停、重试前检查、次数／预算与手动回退；迟到结果、错误跨页引用、设备撤销；EXIF 正向副本、原图不变及重启不重发。只替换外部供应商 HTTP，未绕过实际鉴权、保存与识别模块。

浏览器初步 Edge 通过：上传后候选不自动选中，确认采用、文字更正、保存和原识别对照、同页第二题；重试响应丢失不重复请求，且不覆盖手工文字。后续完整回归、三浏览器、升级、审查与本机更新结果完成后补充。

## 待用户真实材料验证

此项尚未验证四科真实纸质材料及手机操作，不记为通过。已有讯飞后台合成样例实测属于 #13，不能替代学习端本项实测。真实百度凭据尚未配置。

本机更新完成后，使用原家庭 HTTPS 入口和小米 14／Chrome：

1. 每科选择一张真实材料，检查原图完整、方向正确，识别结束后是否有可用文字／范围；记录耗时和失败提示。
2. 点选一道题，检查题干、图形和批改是否完整；调整框选，改一句文字，确认学科／题号并保存。另一设备核对更正内容和原识别对照；确认未选中的题没有自动收集。
3. 从同页再收集一道；重新识别后确认原来手工更正未被覆盖，只有主动确认采用才改变内容。
4. 家长停用识别后新收集一张，检查不发起识别且可手动完成；再启用后检查旧材料不会自行重识别。

记录每科实际效果，不给出推算准确率。复杂公式缺失、候选范围漏图等应记录为能力限制／需人工调整；若影响保存完整原题、调整、找回，应作为缺陷修复。
