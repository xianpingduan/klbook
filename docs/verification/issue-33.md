## 自动化验证

以公开 HTTP、真实隔离 SQLite/附件和完整浏览器流程验证；只替换外部供应商 HTTP。

- 取消及撤销：两设备读取、重复提交、旧修订冲突、已收集题保护、原文件保留。
- 换图：上传失败保留原内容、响应丢失并刷新后继续替换、保留填写信息、只保存一个题目区、取消响应丢失后重试。
- 识别：上传零外发；下一步识别当前区域；同图同范围自动请求复用，改框有独立批次；坐标映射回原图；校验越界与请求 ID 改用范围。
- 保存独立于 OCR：供应商响应挂起时先保存成功，迟到结果不覆盖学科、备注和文字；后台回执丢失后重试仅一次外部调用。
- 识别质量修正：局部无效行保留合格文字并提示部分识别，不重复调用；全部无效或页面错误仍失败；照片使用正向 JPEG 副本；无题号时不逐行冒充题目，学年日期不作为数学依据。
