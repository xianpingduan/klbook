# 图片识别服务管理

任务：[GitHub #13](https://github.com/xianpingduan/klbook/issues/13)。管理入口：`/admin/services/ocr`，需家庭登录和有效家长验证。学习端图片识别接入由 #14 承接，目前仍可正常手动收集。

## 首个供应商

选用百度智能云“试卷分析与识别”，适配 `doc_analysis v1`。纸质作业需要中英文、印刷／手写混排及公式能力，这个接口与当前材料相符；版面块不等于可独立作答的小题，不能直接宣称完成自动分题。选型面向中国大陆使用环境；此接口使用统一官方域名，没有由本应用选择机房地域的参数，实际处理地域以供应商服务条款为准。

- 官方识别接口：`POST https://aip.baidubce.com/rest/2.0/ocr/v1/doc_analysis`，表单编码。后台先向 `https://aip.baidubce.com/oauth/2.0/token` 取得短期 token；token 仅内存缓存，不发送给客户端。保持 TLS 校验，禁止重定向，不允许自定义供应商 URL。
- 已适配参数：`CHN_ENG`／`ENG`、印刷或 `handprint_mix`、公式识别；请求同时开启方向检测及版面分析。当前界面展示规范化的文字和位置结果，不展示未经筛选的供应商原始响应。
- 图片限制：官方支持 JPG/JPEG/PNG/BMP，最短边至少 15px、最长边不超过 8192px，编码后不超过 10MB；本项仅发送服务端生成的 1000×600 PNG 合成样例 `school-v1`。相册格式转换和孩子材料的调用属于 #14。
- 参考计费为按次后付费 0.16 元／成功调用。应用默认月预算 50 元、300 次尝试、单价 0.16 元，可按实际套餐调整；不自动推断免费额度、折扣或账户余额。已返回明确失败的调用释放估算费用，超时／连接中断等不能确认是否成功的调用保留估算。认证失败也占一次本地尝试，但不计识别费用。

依据：2026-09-25 查阅的[产品介绍](https://cloud.baidu.com/product/OCR/doc-analysis.html)、[接口文档](https://ai.baidu.com/ai-doc/OCR/jk9m7mj1l)、[认证说明](https://ai.baidu.com/ai-doc/REFERENCE/Ck3dwjhhu)、[错误码](https://ai.baidu.com/ai-doc/OCR/ckibizxg1)及[计费说明](https://cloud.baidu.com/product-price/ocr.html)。价格可能调整，以账户实际账单为准。

## 讯飞适配（用户追加）

管理页可选择“讯飞 · 通用文字识别”。适配产品为 `textRecg1` 页面对应的 `sf8e6aca1` v1（中英文识别），不混同 intsig、文档大模型或单独的公式服务。固定请求 `https://api.xf-yun.com/v1/private/sf8e6aca1`，使用 APPID、APIKey、APISecret；后台按官方 HMAC-SHA256 规范签名，电脑时间需准确。仅向官方域名发送，保持 TLS 校验，不接受任意 URL。

面向中国大陆家庭使用；适配器没有机房地域选择参数，实际数据处理地域以供应商服务条款为准，不根据接口域名推断物理机房。

支持中英文印刷及手写文字；此接口没有我们已适配的专用公式或分题能力。请求为 PNG 和固定中英文参数，按接口文档的更严格限制控制 base64 后不超过 4MB（产品介绍页标注与接口文档存在差异，以接口文档为准）。返回外层成功仍需核对内层页面、文字行状态，解码文字与四角坐标；不把部分异常结果显示为完整成功。

外层成功但内层异常、结果格式无效时，不自动重试，因无法确认供应商计费而保留估算。鉴权或明确外层失败释放本地估算；原始错误和签名 URL 不回显。

讯飞参考套餐 350 元／1 万次，折合 0.035 元／次。费用预留改为整数厘，保留旧百度金额；后台可填写三位小数单价，也允许将已领取免费包按 0 元估算，但不查询或保证账户免费余额／期限。免费包页面目前标注 10 万次／90 天／每个用户一次，实际以领取页为准。

切换供应商须保存配置；已保存凭据各自保留，未保存凭据清空，切换默认停用。仍只有一个当前图片识别供应商，保存、切换与重新启用均不出网。次数和费用按图片识别能力合计，切换不清零；测试记录保存实际供应商，旧测试归属百度。在途请求使用发起时的供应商与凭据，切换阻止后续重试，已发送结果仍保留。

旧库自动迁移至 schema 11：原百度配置补全供应商、原密文搬至供应商凭据表，不重新输入密钥；旧调用金额保持等值。API 响应新增供应商状态及记录归属，只返回各供应商是否已配置／可读取，不回传 APPID 或密钥。已有旧网页需刷新后使用新版配置字段。

依据：[讯飞通用文字识别产品与免费包](https://www.xfyun.cn/services/textRecg1)、[官方接口及签名文档](https://www.xfyun.cn/doc/words/universal_character_recognition/API.html)，核对日期 2026-09-25。当天用户已通过本机真实凭据样例测试，返回 5 行文字与位置；详情见[验收记录](verification/issue-13.md)。百度真实调用、供应商账单及四科实际纸质材料的效果尚未验证。

## 家长操作

1. 选择供应商，在对应控制台开通服务并创建应用：百度需试卷分析与识别权限，讯飞需通用文字识别权限。只在本机管理入口填写凭据；百度为 API Key／Secret Key，讯飞为 APPID／APIKey／APISecret，不在聊天、议题或截图中发送凭据。
2. 保存配置。保存、读取和启用开关均不发起外部调用；未配置时默认停用。凭据输入在成功保存或管理授权到期后清空，其他未保存设置可保留。
3. 核对页面中的合成测试材料，点击“发送样例并测试”。即使尚未启用，也允许家长明确发起这一次测试；每次尝试和重试都受额度约束。合成样例不包含孩子照片或个人信息。
4. 查看成功／错误摘要、耗时、尝试次数和识别文字，人工核对后决定是否启用。一次合成印刷样例成功不能证明真实手写、复杂公式或所有学科识别准确。

### 讯飞鉴权失败

后台对官方已知鉴权错误分别显示 APIKey 无效、签名不匹配、无法验证签名或时间异常；只显示固定说明，未知响应仍使用通用提示，不显示原始响应及签名 URL。

- **APIKey 无效**：到讯飞控制台的通用文字识别页面，重新复制同一应用下的 APPID、APIKey、APISecret，一起填写并保存；核对未混用 intsig、OCR 大模型或其他应用的凭据。若原凭据已重置，应使用新凭据。
- **签名不匹配／无法验证签名**：核对 APIKey 与 APISecret 是否为同一应用、是否完整复制；仍失败时保留错误类别供排查，不分享密钥。
- **时间异常**：同步家庭电脑系统时间，再主动测试；官方接口要求时间偏差不超过 300 秒。

依据：[讯飞官方鉴权说明](https://www.xfyun.cn/doc/words/universal_character_recognition/API.html)。鉴权失败不自动重试，不计本地识别费用。

## 调用与保存约定

- 配置采用修订号和操作 ID，阻止覆盖其他页面修改。配置审计记录账号名称、操作时间及保存／替换凭据／启停／主动测试，不包含字段值或密钥。
- 测试使用持久操作 ID。HTTP 返回丢失时重试同一个 ID，读取已有测试；后台不会重复发送。页面刷新后可读取最近 20 次测试，配置审计显示最近 30 条，底层记录保留。
- 每次外部尝试前，以短事务检查额度并预留次数和估算金额。网络请求不在数据库事务中。百度认证完成后、实际发送图片前再次确认配置修订未变化。
- 最多重试 0～2 次，仅对网络、超时、限流和临时服务错误重试，有短暂退避。每次重试重新检查配置和额度。更改配置（包含停用）会阻止尚未发送的调用及重试；已经发送的请求允许返回并保留结果。
- 配置默认停用，重启、启用、读取配置均不扫描历史资料。服务中断后未完成记录标为结果不确定，不自动重发，估算金额保守保留。当前只有家长明确操作的合成样例调用；#14 新增业务入口必须在本次尝试与每次重试前同时检查启用状态和额度，不能沿用家长主动测试的停用豁免。
- 用量按北京时间自然月汇总。当前仅图片识别额度；#17 承接三类服务汇总，不能把这里的 50 元说明成将来三类能力的共同上限。

## 凭据、备份与后续能力

凭据采用 AES-256-GCM 加密后保存到 SQLite，独立密钥为数据目录中的 `service-credentials.key`。文件不经 API／静态资源提供，API 只返回配置与可解密状态；不打印供应商 URL、原始错误或响应体。能同时读取数据库和密钥的本机用户仍能解密，应使用受控 Windows 账号和数据目录权限。

完整安装备份必须同时包含一致 SQLite 快照、附件和配套密钥；学习资料导出不得包含供应商凭据或本机密钥。已有加密凭据时若密钥缺失，不会生成新密钥覆盖旧关系：仍可停用，恢复配套密钥后再调用。本项未交付完整备份／导出功能。

后续语音转写、AI 学习服务各自配置和开关，不能以图片识别开关代替。复用修订与操作 ID、服务端凭据保护、按能力审计和用量预留的约定；新增能力需独立适配真实接口，凭据加密的附加认证数据也需按能力区分。当前不预造供应商插件、未实现菜单或总开关。
