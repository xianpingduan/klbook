# 学科、学习阶段与查找

对应 [#8](https://github.com/xianpingduan/klbook/issues/8)，使用既有学习端与管理端布局。

## 使用方式

- 家长在“学科与学习阶段”中新增学科，初始语文、数学、英语、科学保留。名称去除首尾空格，拒绝同名；新增重试沿用同一学科身份。当前只新增，不提供改名、停用或删除。
- 当前学年、年级和学期均选填。学年使用连续两年，如 `2026-2027`；年级可填写“小学四年级”等名称，不锁定当前小学阶段；学期为上学期、下学期或未设置。
- 新题默认带入阶段，每题独立保存；在题目确认或更正页可单独修改、清空。收集日期独立记录，补收旧材料不改收集日期。未设置阶段、来源或备注均不阻止收集。
- 首页与后台错题资料列表提供折叠的“筛选错题”，按学科、学年、年级、学期、来源组合查找；已收集列表另支持收集日期范围。条件之间为“同时满足”，每项可选“全部”或“未设置”。停用来源仍可用于查找旧题。
- 日期按当前设备的本地日历，包含开始与结束当天。应用筛选后打开详情、返回和加载更多沿用已应用条件；清空筛选恢复全部。切换后台草稿状态时清除收集日期条件，避免把尚无收集日期的草稿排除。

## 默认值与暂存

选图时读取家庭默认阶段，并随整批实际图片保存到设备暂存；批次后续图片不会因家长修改默认值而改归属。默认设置读取失败时使用最近已读取的阶段，从未读取则保留未设置；之后可在题目中更正。

旧版本设备暂存没有阶段信息时按未设置恢复，不套用升级后的当前默认值。已创建的服务端草稿使用记录中原有阶段；最初上传操作重放以服务端首次接收结果为准，不修改该记录。新增同页小题使用新建时读取的家庭默认阶段，既有题目不变。

管理配置沿用后端家长二次验证，日常学习会话可读默认值并更正单题，不能更改家庭配置。未保存输入受到离开保护；授权到期后重新验证保留输入。设置以修订号与稳定操作 ID 处理失败重试和并发冲突，不覆盖其他设备的新设置。

## 数据与接口

结构版本 9 为题目新增可空 `schoolYear/grade/term` 列，旧行保持未设置；新增家庭默认设置及重试记录。默认设置更新不会批量重写题目。

- `GET /api/v1/collection/subjects` 保留原学科读取；`PUT /api/v1/admin/subjects/:id` 以稳定 UUID 新增学科。
- `GET /api/v1/collection/study-settings` 读取默认阶段；管理端 `GET/PUT /api/v1/admin/study-settings` 需要家长验证。写入包含 `operationId/expectedRevision/stage`。
- 题目返回 `studyStage`；普通建题与更正请求可携带该字段。旧客户端省略字段时更正保留当前题目阶段，建题使用当时默认值；旧操作哈希保持兼容。
- 上传新草稿可携带 URI 编码 JSON 的 `X-Learning-Stage`，用于冻结设备暂存阶段；原始页追加不改变题目归档。原上传操作标识及图片哈希继续用于幂等重试。
- `GET /api/v1/collection/filter-options` 提供已有学年、年级与全部来源；题目列表接受 `subjectId/schoolYear/grade/term/sourceId`，`__unset__` 表示未设置。`collectedFrom` 为含端点起始毫秒，`collectedBefore` 为不含端点截止毫秒；列表总数和分页使用同一条件。

本任务实现结构化筛选。识别文字与人工更正内容的关键词检索待对应能力落实后另定；当前未宣称全文检索已完成。导入导出与备份任务应保留单题实际阶段，不能恢复时套用家庭当前默认值。
