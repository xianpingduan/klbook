# 共享阅读材料

对应 [#6](https://github.com/xianpingduan/klbook/issues/6)。学习端和后台沿用现有题目整理入口，原文不单独成为一道错题，也不新增导航入口。

## 使用方式

1. 打开已保存的小题并进入整理页面。在“阅读材料（选填）”选择已有原文，保存题目后建立关联。
2. 没有合适原文时，选择“从原始页新建阅读材料”。为原文起名，在本题原始页中框选阅读内容；移除不需要的页或区域，点击“保存并返回题目”。材料保存后会关联当前小题。
3. 通过“编辑已关联原文”补充内容；支持追加原文图片、补画同页区域、重画、清除、移除和调整顺序。每次追加一页，保存后可继续；每篇最多 50 个原文区。新原文先保存，再追加新图片。图片沿用 JPEG、PNG、静态 WebP 的限制。
4. 其他小题可以选择同一篇原文。从已关联的小题继续收集同页新题时，会带入该原文，确认信息时可以更换或清空。
5. 每个小题仍在列表中独立出现，详情同时显示题目和完整共享原文。“查看原始页”包括题目与原文使用的全部原始图片，同一张图片只展示一次。
6. 选择“不关联阅读材料”并保存，只解除当前题的引用。原文和其他小题不会删除；即使暂时没有题目引用，材料仍在选择列表中，可重新关联。

当前每道小题可关联一篇阅读材料，一篇材料可包含多个有序页面或区域。材料名称用于查找，可更正；材料列表分页读取。更正共享原文会更新所有引用它的小题，编辑页面显示已关联小题数量。

## 保存与失败恢复

- 原文与题目分别拥有稳定身份和修订号；更正原文不会改变小题身份或收集时间。
- 新建原文与关联题目分两次确认：原文必须完整保存后，才提交题目引用。关联请求失败时原文已可从列表找回，题目不会指向未保存的材料；重试沿用原操作标识。
- 保存响应丢失后，重放未确认的请求再保存后续更改，避免重复创建。修订冲突保留当前输入，需返回题目并重新打开核对，不覆盖其他设备已确认的修改。
- 追加图片保留在当前网页来源下，按家庭资料库、账号与材料身份隔离的设备暂存中；材料保存引用后才清理。重新打开原文可续接未完成追加，可能需要重新框选。未保存表单继续使用离开保护，不承诺关闭页面后恢复全部未提交范围。
- 家长管理授权到期后暂停管理写入，重新验证可继续；普通学习会话可整理自己的家庭材料。附件读取均经过应用鉴权。

## 后续功能沿用的引用规则

数据库结构 7 新增阅读材料、有序区域、题目引用和幂等操作记录；旧题默认不关联原文，已有题目与原图不变。题目保存请求省略 `readingMaterialId` 时保留旧引用，明确传 `null` 才解除。

题目引用阅读材料的稳定 ID，阅读区域引用原始页 ID；不复制文件作为关联。引用由外键约束保护，界面显示的引用数量不能替代实际关联检查。

- **回收站与清理（#18）**：解除单个引用或移除区域不删除材料/图片。永久删除前必须检查仍有效的题目、阅读材料和后续解答区引用；本项不实现自动清理或材料删除。
- **导出/导入（#19—#21）**：从选定题目沿引用收集完整原文、每个有序区域与原始页，按稳定 ID 去重，并保留共享关系。暂时无引用材料的导出范围由后续任务决定。
- **备份（#23—#24）**：包含同一一致快照中的全部资料表与实际附件，不能只备份当前某题的题目图。

公开接口：`GET /api/v1/collection/reading-materials?offset=0`、`GET/PUT /api/v1/collection/reading-materials/:id`；新建使用客户端稳定 UUID 和 `expectedRevision: 0`，后续更正提供已有修订。题目详情返回 `readingMaterial`，原有保存接口支持可选 `readingMaterialId`。

验收证据见 [#6 验证记录](verification/issue-6.md)。
