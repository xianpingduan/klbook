## 实施结果

资料页改为按已收集/草稿分组的真实分页表格，每行一个打开入口；详情在宽屏左图右表单、窄屏上下排列。资料页提供唯一上传入口，沿用批次、取消、草稿续接、原图和修订/幂等规则。来源独立表格支持新增、改名、停用、启用，并保护未提交表单。

后台资料请求附加管理授权；服务端拒绝失效的管理请求，普通学习权限保持原约定。授权到期或被撤销后，重新验证可继续原材料与表单；保存离开失败不跳走。重新编辑时隐藏上一次的已同步提示，避免误报本次修改已保存。

## 自动化

全部使用隔离的真实 SQLite、文件和 HTTP API，不使用家庭资料库作为测试数据。

- `npm run build`：类型检查和前后端构建通过。
- `npm test`：19 个 API 测试全部通过；Edge、Firefox、WebKit 各 25 个浏览器场景，共 75 项全部通过。
- 完整回归后补充“编辑后不能继续显示旧的已同步提示”断言，确认失败后修正；三个引擎中相关 12 项复测全部通过。其余 63 项沿用上述完整回归结果。
- 新增 6 个端到端场景：后台批量续接与离开保护；服务端撤销管理授权后上传/保存被拒绝；53 条资料的分组、分页与读取失败重试；来源输入、刷新、验证失败/到期和退出保护；来源重名、并发冲突及保存离开时撤权；后台上传、更正、响应丢失重试和另一学习会话找回。
- 既有来源场景补充：后台更正关联已停用来源的题目，学习端读取一致名称和备注。API 测试补充：失效管理请求返回 403，普通学习上传与保存仍成功，未授权来源管理仍被拒绝。
- 390、820、1440 CSS 像素检查无页面横向溢出；管理表格内部滚动可由键盘聚焦，窄屏可以滚动至保存按钮。实际查看了表格、详情、来源页的宽窄屏截图。

测试截图保存在 `test-results/`，定向回归与失败证据在 `.scratch/issue-31/`。视口模拟不代表真实软键盘、系统相机或 iOS 设备通过。#30 的新版真机待验证状态保持不变。

结果：设备凭据字符串不变，旧题完整读取结果与来源身份不变，原图字节一致；后台可以更正旧题且保留身份与收集日期，可以继续旧版暂存图片，最终恰好两道已收集题。记录见 `.scratch/issue-31/upgrade-probe.mjs` 与 `upgrade-result.json`。
