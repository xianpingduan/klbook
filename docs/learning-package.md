# 学习资料包导出（格式 1）

任务：[导出完整学习资料包 #19](https://github.com/xianpingduan/klbook/issues/19)、[校验预览并完整导入 #20](https://github.com/xianpingduan/klbook/issues/20)。冲突副本、回收站恢复和手动学科对应由 #21 扩展。

## 使用

在家长管理的「资料导出」完成验证，核对题目数、原图数、学科、学习阶段、收集日期和本机待处理内容，然后生成并下载 ZIP。下载完成需在浏览器下载记录或系统文件中确认；页面不会宣称文件已写入用户指定磁盘。

普通学习资料包仅包括当前学习者在家庭资料库中已同步、未删除的已收集题目及必要引用。草稿、回收站、其他设备尚未上传的内容，以及账号密码、会话、服务配置和供应商凭据不在其中；不能代替完整资料库备份。原始页本身可能同时包含多道题的纸面内容，保留原图不等于把其中其他题目的记录一起导出。

当前设备的待上传图片和待处理题目分别计数；同一题目可能有图片也有文字待处理，这两个数字不相加为题目数。提示只反映此设备能访问的当前资料库暂存，其他设备的未上传内容无法由服务器枚举。

预览后若资料已更新，生成接口返回冲突，需要刷新范围再核对。任务接受后固定快照，随后修改不会进入此包。管理验证到期后重新验证可继续下载同一份已生成包。临时包生成后保留 15 分钟，服务重启后失效；服务器一次生成一份，最多保留三份未过期任务，避免无限占用磁盘。重新生成前释放旧失败任务的名额，因此修复故障后可以继续重试。请将下载文件保存在需要的位置。

## ZIP 内容与完整性

- `manifest.json`：`format = klbook-learning-package`、`version = 1`、资料包 ID、快照时间、来源资料库 ID、题目数及文件清单。
- `manifest.sha256`：原始 `manifest.json` 字节的 SHA-256 十六进制摘要及换行。用于发现意外损坏，不是可信签名或加密。
- `data.json`：下述结构化学习记录。清单记录该文件的字节数和 SHA-256。
- `images/<原始页 UUID>.<jpg|png|webp>`：实际上传原图，按原始页 ID 去重；每个文件均有字节数及 SHA-256。原图方向元数据保留，题目坐标使用应用既有自动校正方向后的归一化坐标。

清单除自身及其摘要外枚举所有文件；包内关联使用稳定 ID 和相对路径，不使用下载地址、预览 URL 或绝对磁盘路径。ZIP 由 `yazl` 流式写入临时文件；原图逐张读入并核对已有 SHA-256，避免把全部原图同时放入内存。库 API 依据 [yazl 官方文档](https://github.com/thejoshwolfe/yazl)。测试用独立的 `yauzl` 读取 ZIP 并核对文件清单。

`data.json` 的公开契约见 `src/shared/learning-package.ts`：

| 集合 | 保留内容 |
| --- | --- |
| library | 稳定来源资料库 ID、学习者 ID 与名称；不包含账号登录信息 |
| questions | ID、学习者、修订、学科与来源身份、来源显示名、页码题号备注、原创建/更新时间与收集日期、学年年级学期、按顺序排列的题目区和解答区、共享阅读材料 ID |
| readings | ID、修订、标题、原创建/更新时间、有序原文区域；同一原文仅存一次 |
| pages | ID、原图相对路径、类型、字节数、SHA-256、校正方向后的尺寸 |
| subjects / sources | 题目引用的学科身份和名称（含扩展学科）；来源身份、名称、启用状态和修订 |
| recognitions | 所需原始页已成功完成的识别记录：ID、修订、时间、输入尺寸和范围、原识别文字与候选题目；人工更正文字及识别引用另存于题目区 |

有序数组的位置就是图片顺序，不按文件名重新排序。学习阶段未设置时保留 `null`，不带入当前默认阶段。来源资料库 ID 与记录 ID 共同标识来源，后续导入用修订和内容判断重复与冲突。服务测试样例和失败诊断不属于学习识别内容。

## 一致性与清理

1. 在短 SQLite 事务内读取全部学习记录、引用与摘要，形成公开 DTO；预览令牌覆盖这些内容并绑定当前账号。
2. 生成时重新核对令牌，在同一事务中固定 DTO 并登记 `exportPagePins`。事务结束后才读取图片和打包。
3. 回收站允许并发删除题目，但被导出占用的原图与识别记录延后清理，确保快照可完整读取。包生成或失败后释放占用，后续回收站清理继续进行。
4. 只有 ZIP 完整写出后才标记可下载。缺图、摘要不符或写入失败时返回失败状态，不提供残包，不修改学习记录。
5. 重启时清理本应用导出工作目录中的 UUID 子目录并释放上次导出占用，然后执行回收站清理；临时文件不作为持久备份。下载中不清理其文件。

预览、生成、任务查询和下载分别由后端验证当前设备会话及家长授权。生成接受前的异步清理完成后再次验证权限。响应只返回明确列出的学习字段；数据库文件、原始 SQL 行、服务配置与操作日志不放入包内。

## 公开接口

- `GET /api/v1/admin/exports`：范围预览与令牌。
- `PUT /api/v1/admin/exports/:id`，`{ previewToken }`：固定快照并异步生成。客户端保存 UUID 重试；同任务同令牌返回已有任务，不重复生成，其他令牌返回 409。
- `GET /api/v1/admin/exports/:id`：生成中、已生成或失败状态。
- `GET /api/v1/admin/exports/:id/file`：已完成 ZIP 的受保护下载；过期、重启、权限失效或生成失败不返回包。

所有接口使用配置的服务地址；浏览器下载也通过带凭据的应用请求完成，不把凭据放到 URL 中。客户端最多等待下载五分钟，不限制后台生成只能在单个 HTTP 请求内完成。

## 导入

家长管理「资料导入」选择 ZIP 后自动校验，再核对来源学习者、目标学习者、新增与完全相同的数量、材料数量、学习阶段及学科归属，点击「确认导入」。确认前只写独立工作目录，题目列表不会提前出现资料。选错文件可重新选择或移除预览；不删除已导入的资料。

支持格式 1，接受该格式省略 `studyStage` 的兼容记录，并将其补为全部未设置；字段存在但结构不完整时拒绝，不猜测归档，不套用或修改当前家庭默认值。导入保留原创建、更新、收集时间与修订，另存 `importedAt` 并在题目详情显示。普通学习包不恢复账号、会话和服务配置，所有服务均可保持停用。识别记录标为「资料包识别记录」，不伪称本机调用，不进入服务调用统计。

### 校验与资源范围

- 上传流写入服务器生成的 UUID 工作目录，不将整个 ZIP 放入内存；当前上限 512 MB，解压总量 1 GB，最多 10000 张原图、10000 道题。
- `data.json` 最多 16 MB，每张图片最多 15 MB、4000 万像素，沿用采集格式 JPEG、PNG、静态 WebP。原图逐张解码并生成预览，核对真实类型、校正方向后的尺寸及 SHA-256。
- ZIP 逐项读取，只接受清单、摘要、结构化记录及规范原图路径。拒绝重复文件、路径穿越、符号链接、特殊文件、加密条目及不支持的压缩方法；实际解压字节受单文件和总量上限约束。
- 检查清单及逐文件摘要、格式版本、结构、重复身份、学科/来源唯一名称、全部题目区/答案区/共享材料/识别引用、数组顺序和范围。额外未知字段、孤立材料或缺图均拒绝。完整性摘要用于发现损坏，不是来源可信签名。
- ZIP 读取基于 [yauzl 官方接口](https://github.com/thejoshwolfe/yauzl)，使用逐项处理、严格文件名和大小检查；包中路径只用于比对，不作为磁盘写入路径。

### 重复、冲突与原子提交

来源资料库、实体种类和原记录 ID 共同保存为稳定来源映射；目标库分别生成题目、原图、阅读材料、识别记录等 ID，并统一转换全部引用。来源和目标内容摘要同时记录，只有来源版本、内容与目标当前内容均相同才跳过。当前阶段不自动覆盖已有修改，已删/回收站记录、身份碰撞和待人工确认的学科关系阻止整批提交。

预置学科按应用内固定身份匹配；新的自定义学科在目标库没有同名项时预览为新增。同名但身份不同的学科不凭名字合并。来源可复用名称、启用状态与修订完全相同的列表项；存在差异则阻止提交，不改变已有来源设置。

校验和预览期间不发布任何学习记录。确认时先记录新附件清理意图，再准备并同步写入全部原图/预览，核对已有附件仍可读；随后在短事务中重新验证家长权限、范围令牌和全部映射，一次写入整批记录、引用、稳定来源映射与成功回执。失败回滚记录并清理未发布文件；重启按持久清理意图移除未发布附件，不删除已提交附件。

同批同令牌的确认重试返回持久成功回执；再次选择相同资料包会重新校验并跳过未变记录。处理中其他提交返回稍后重试，不创建第二份内容。预览在内存保留 30 分钟，最多两份，同时只处理一份上传/提交；服务重启使未提交预览失效，成功回执仍可查询。网页按服务地址、资料库和账号隔离保存本标签页的批次标记，刷新后经家长验证继续查看；浏览器无法保留标记时可重新选择原包安全重试。

### 导入接口

- `PUT /api/v1/admin/imports/:id`：`application/zip` 二进制上传，返回校验后的预览或该操作的既有成功回执。
- `GET /api/v1/admin/imports/:id`：重新核对当前预览，或返回成功回执。
- `POST /api/v1/admin/imports/:id/confirm`，`{ previewToken }`：核对后原子应用；过期预览或冲突不写入学习记录。
- `DELETE /api/v1/admin/imports/:id`：移除未提交的暂存包；对已完成批次不删除学习资料或回执。

全部接口由后端验证设备会话和家长授权；文件处理后的发布前再次验证权限。客户端使用配置的服务地址，上传和确认最多等待五分钟；超时后先读取批次结果或重试相同操作，不以超时推断服务器未完成。
