# 后台设备与账号

家长从 `/admin/devices` 或后台侧栏的“设备与账号”进入，验证家长密码后使用。设备表格与恢复码保管各有独立区域，概览及学习首页不增加快捷入口。

## 设备访问

- 表格列出实际有效会话、当前设备、登录时间和到期时间；窄屏在表格内部横向滚动，侧栏通过“管理菜单”打开。
- 撤销其他设备后，服务端立即拒绝它的请求。设备列表重新读取，回到概览时计数更新。
- 撤销当前设备后进入登录页，旧设备会话和管理授权不可再用；浏览器无法清除登录记录时也立即关闭当前管理界面，并如实提示存储问题。
- 读取失败显示不可用并提供重试；操作响应丢失不声称成功，允许刷新或重试。重复撤销遵循既有接口规则，不影响其他设备。

设备撤销不会删除家庭资料或本机材料。待上传批次继续使用服务地址、资料库和账号的隔离规则，不能转入另一家庭。

## 恢复码与账号恢复

重新生成恢复码需有效管理授权，旧码立即失效，同时清除该设备已有管理授权。请求处理期间阻止切页，避免离开后错过新码。

已成功的恢复码生成或当前设备撤销响应，即使晚于管理授权到期，也由原设备会话接收；该会话已退出或换成新会话时，忽略原操作的迟到结果。

新码仅在当前页面内存中显示；勾选保存确认后才可继续。站内返回、后退受到保护，刷新或关闭使用浏览器离开提示。确认后清除页面中的码，再次进入管理需重新验证；不将恢复码写入普通草稿或浏览器持久存储。强制关闭后不能重新读取同一码，仍记得密码的家长可登录后重新生成。

登录页可以使用已保存的恢复码设置新密码，旧设备会话及管理授权全部失效。原家庭资料不变；新会话保存新恢复码后，继续原允许的站内目标，例如 `/admin/devices`，并重新验证家长身份。

## 管理授权与退出

管理授权沿用五分钟有效期及设备绑定；本机到期或服务端拒绝时锁定后台。非敏感未提交表单按既有规则保留，密码、管理令牌和恢复码不作为草稿持久保存。

顶部仅保留一个“结束管理”。操作先经过共同的未保存表单保护，服务器撤销成功后返回学习端；失败留在原页提示重试，再次进入后台需要验证。

验证证据与真机边界见 [#32 验证记录](verification/issue-32.md)。
