# AI 学习服务管理

任务：[GitHub #16](https://github.com/xianpingduan/klbook/issues/16)。入口：`/admin/services/ai`，需要家庭登录与有效家长验证。

## 本次范围

家长后台独立配置、启停和发送明确的文字测试，查看模型回复、耗时、token 计量、尝试次数、估算费用及配置审计。测试内容和回复保存在测试记录中，不新增错题，不修改题干、标准答案或孩子自己的总结。孩子端提示、讲解、拓展练习、错因总结与解题思路由后续任务实施。

## 实际供应商适配

2026-10-19 核对[讯飞官方 HTTP 文档](https://www.xfyun.cn/doc/spark/HTTP调用文档.html)，采用固定 HTTPS 地址 `https://spark-api-open.xf-yun.com/v1/chat/completions`，非流式返回，提供 `lite`（Spark Lite）与 `4.0Ultra`（Spark Ultra）两个模型。官方已说明 Ultra 后端升级，其名称不代表固定权重版本；未采用已公告下线套餐的 Max 作为默认选项。

鉴权使用对应模型 HTTP 服务的 **APIPassword**，不能用 OCR／语音的 APPID、APIKey、APISecret 字段代替。不同模型默认密码可能不同，本应用按模型分别加密保存，切换模型不传递另一个模型的凭据。产品和实际开通、有效期、授权额度由[讯飞控制台](https://console.xfyun.cn/)核对；应用不代为开户、不保证永久免费。

仅发送页面中显示的文字作为一条 `user` 消息，无隐藏系统提示、历史对话、图片、音频、题目引用或本地账号标识。Ultra 显式关闭联网搜索及函数调用；Lite 不发送其未支持的工具参数。回复作为纯文字显示，不执行模型输出的 HTML、脚本、链接或工具调用。

该接口无地域选择参数，本版本不宣称特定物理机房；不接受任意供应商 URL。请求不跟随重定向，防止凭据被转发至其他地址。既有服务地址设置仍只控制客户端连接家庭电脑，与供应商地址分开。

## 配置、启停与测试

- 默认停用、Lite、最大输出 512 token、单次超时 60 秒、自动重试 0 次。保存和启用都不调用模型；重新启用不扫描旧材料。
- 测试内容为 1～2000 个字符，不能全为空白；最大输出可设 1～2048 token，超时 5～120 秒，自动重试 0～2 次。输出达到上限时保留返回文字并提示可能不完整。
- 新测试与每次重试都校验家长权限、配置版本、AI 自身开关、次数及预算。修改配置会停止尚未发送的重试，已经发出的调用保留实际成功或失败，不伪改为取消。
- 同时只处理一项 AI 测试。测试 ID 绑定账号、文字和配置修订；响应丢失后重放同一请求不再次调用，更换内容不能沿用该 ID。页面会保留原请求用于明确重试。
- 网络断连、超时、异常响应和停服显示结果不确定；重启保留遗留状态，不自动重发。服务端不会把供应商原始错误报文或鉴权头返回页面；按官方错误码分别提示输入审核、输出审核、输入过长、权限、日限额和并发限制。未知业务错误保留费用不确定状态。
- 不控制 OCR 或语音的开关，三类能力分别记账。切换 AI 模型不清空 AI 本月次数和历史测试记录。

## 用量和估算

token 是模型的文字计量单位，不等于字符数。记录供应商返回的有效输入、输出和总 token；缺失、负值或不一致的计量标为未知，不伪报为零。月度页同时显示尝试次数、已有有效计量的次数及这部分 token 合计。最近 20 项测试、最近 30 项审计供页面查阅，月度统计不只计算这 20 项。

按模型分别填写**输入／输出每百万 token 单价**，价格与确认状态独立保存。没有预设商业报价；启用前必须明确确认所选模型的价格，即使免费额度内填 0 也要确认。修改价格会撤回该模型的确认状态；切换到未确认价格的模型不会继续启用。免费包余额及有效期不自动查询，实际费用以供应商账单为准。

每次发送前按模型最大输入（Lite 8192、Ultra 32768 token）和本次最大输出保守预留预算，不用字符数冒充准确 token 数。收到有效计量后，按该次请求的价格快照计算输入与输出费用并替换预留；重试分别计量。以整数微元保存，每次最多向上舍入一微元，页面显示六位小数。例如输入 28 token 按 ¥2／百万、输出 19 token 按 ¥6／百万，费用估算为 ¥0.000170。

成功但计量缺失、超时、断连、输出审核和未知错误保留预留费用并标明待计量；明确拒绝且未报告消耗时释放预留。错误响应即使 HTTP 非成功状态，返回有效 token 也照实记录并估算。月度汇总包含待计量预留，单次记录分别展示总估算和其中的预留。北京时间自然月统计，每次失败和重试计入尝试次数，超过预算不再发出新尝试。三类服务汇总预算属于 #17，不把本页限额等同于全家庭总预算。

## 权限与保存

所有 API 在处理正文前验证设备会话和家长短期授权。配置保存使用修订号和操作 ID，防止多页面静默覆盖或丢失响应后的重复操作。离开管理或验证到期后清空未保存的 APIPassword，已保存凭据不回填页面。

沿用 AES-256-GCM 和本机 `service-credentials.key`，AI 使用独立附加认证数据。`CredentialVault` 将 AI 模型凭据纳入统一检查：任一能力已有密文时，都不能因密钥缺失而重新创建替代密钥。仍允许停用，恢复配套密钥后才可调用。安装备份必须包含一致数据库与配套密钥；普通学习资料包不应包含服务配置或凭据。

新增 AI 配置、模型凭据、测试和尝试记录表，通过追加迁移保留原资料库、账号和其他服务数据。测试文字本身会保存至家庭电脑；真实凭据、鉴权头和原始供应商响应不写入日志或普通测试记录。

## API

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/admin/ai` | 安全配置投影、各模型凭据状态、本月用量与最近测试／审计 |
| `PUT /api/v1/admin/ai` | 配置、可选新凭据、`operationId`、`expectedRevision`；保存不调用 |
| `PUT /api/v1/admin/ai/tests/:id` | 明确的 `prompt` 与 `expectedRevision`；返回 202 和测试记录，配置接口读取后续结果 |

## 真实服务验收

用户已明确“尚未开通，先完成适配”。本轮不要求开户；完成以下实测前 #16 保持开放：

1. 在讯飞控制台选择已开通的对应模型，核对授权、输入／输出单价、额度和有效期；将 HTTP APIPassword 和计量价格填入本机后台，确认所选模型价格，不发送凭据到聊天或议题。
2. 保存配置，确认未产生调用；启用后核对页面测试文字，主动发送一次短测试。
3. 核对实际回复、耗时、token 和控制台用量。刷新页面后记录仍可查看，错题资料和标准答案没有被修改。
4. 停用后确认新测试被阻止、旧结果保留，OCR 和语音配置不变。若同时开通两个模型，分别验证对应凭据，不能把单模型实测记为两者均通过。
5. 仅记录日期、模型、测试文字、结果、计量和错误，不记录密钥。模拟供应商自动化不替代本项实测。
