# 资料导入与导出

用户在 Q38 提出导出应配套支持导入。收集版纳入本应用资料包的导出与导入恢复；以下为设计规则，尚未实现或验证。范围见[收集版需求](collection-v1.md)。

## 用途与首版范围

- 家长可以保存一份独立资料包，之后导入本应用，用于恢复或迁移已有整理结果。
- 同一家庭账号更换访问设备时，在局域网内连接本地电脑上的家庭资料库即可获取已同步资料；不需要每次换设备都导出再导入。更换保存资料的电脑时，可安装应用后通过资料包迁移收集内容。
- 首版导入对象是本应用支持版本的资料包。相册图片仍走已有选图收集流程；第三方错题软件、任意 PDF 或 Word 的结构化导入未纳入本次范围。打印题单仍是后续候选功能。
- 导出、导入均属于家长管理操作；资料包不用于恢复账号密码、设备登录状态或外部服务配置与密钥。

## 资料包内容

设计采用带格式版本的自包含资料包（建议 ZIP，内含结构化清单与实际文件），不依赖会过期的图片下载地址。

| 内容 | 需要保留的信息 |
| --- | --- |
| 题目与原始材料 | 原始图片、题目区和解答区的范围、关联关系、跨页顺序 |
| 阅读材料 | 共享原文及其与各小题的引用关系 |
| 识别与整理信息 | 已保存的识别文字、人工修改后的文字、学科、学年、年级、学期、收集日期、来源、页码、题号和备注 |
| 自定义学科 | 学科标识、名称及题目归属，支持导入时对应到目标学科 |
| 恢复依据 | 资料包版本、导出时间、记录的稳定标识与修订信息、文件完整性校验信息 |

后续上线录音和学习记录时，应同步扩展资料包格式，保存实际已有的原录音、转写与学习记录。自己的解题思路功能上线时，同样保留其文字、语音、手写照片及与错题和后续补充的关联；首版不虚构尚未产生的学习数据。

首版默认导出当前账号在本地电脑家庭资料库中已同步、未删除的已收集资料及其完整引用材料。导出前展示范围和数量，并提示当前访问设备是否还有未同步内容；草稿、回收站和其他设备尚未上传的内容不计入这份资料包，界面不能将其标为全账号备份。资料包内的记录与文件按同一导出快照生成，避免导出过程中修改题目造成关联不一致。

资料包可下载到家长选择的设备或磁盘。保存到资料库所在的同一块磁盘，不能应对该磁盘损坏；建议另存一份到已有的其他设备或移动硬盘。整机恢复还需要数据库与附件的一致备份，以及单独受保护的系统配置，见[本地部署与存储](local-deployment.md)。

## 导入流程

**家长验证 → 选择资料包 → 校验与预览 → 处理冲突和学科对应 → 确认导入 → 查看结果**

1. 检查格式版本、清单结构、文件完整性及引用是否齐全；损坏、缺少必需文件或版本不支持时说明原因，不写入现有资料。
2. 预览将新增、跳过和冲突的题目数量，以及学科对应关系；家长确认后才应用变更。
3. 完全相同的记录跳过。依据来源标识、修订和内容判断重复，不仅比较文件名；不同照片是否拍了同一道题不作自动去重承诺。
4. 同一记录已被修改时，默认保留当前资料，家长可选择将导入版本另存副本；不使用导入时间自动覆盖当前版本。副本保留来源信息，重复导入同一版本不会继续生成相同副本。
5. 对仍在回收站中的同一记录，预览时单独标明，需要家长明确选择恢复；导入不能悄悄撤销删除。
6. 学科标识一致时沿用已有学科；来自其他资料来源的同名或未知学科提供对应建议，由家长选择合并到现有学科或新增。名称相同不直接认定为同一个学科。
7. 导入时统一转换题目、文件和共享材料的引用；另存副本也要保持答案归属、跨页顺序和共享原文可用。
8. 校验和上传暂存在独立批次内，完成后再使整批资料可见。中断或失败不留下半道题；重试不重复添加。最终显示实际新增、跳过、冲突处理结果及同步状态。
9. 保留题目原有学年、年级和学期，不套用目标资料库的当前学习阶段；支持的旧格式缺少这些字段时标记为未设置，允许导入后补齐。导入题目不改变家长设置的当前学习阶段。

导入保留原收集日期，并另记本次导入时间。导入不重新识别图片、不重新转写录音、不调用 AI，也不修改三类服务的启用状态；后续重新处理须由用户主动发起。

## 验收重点

- 导出含自定义学科、跨页题、答案和共享阅读材料的资料包，导入空集合后逐项对照，信息与关联完整保留。
- 不同学年、年级和学期的题目导入后保持原归属；缺少归档字段的兼容旧包保留未设置，不因导入时点而自动改成当前阶段。
- 同一资料包重复导入，未变化的记录不新增；处理过的冲突副本不反复生成。
- 当前题目已修改、已在回收站或学科重名时，预览和结果遵循上述规则。
- 损坏、缺文件、版本不支持、导入中断及重试，均不覆盖原资料或暴露不完整记录。
- 三类外部能力都停用时仍能导入，且不会产生识别、转写或 AI 调用。

后续版本必须声明支持的资料包版本并提供必要的转换；不能将未知版本按当前格式猜测导入。
