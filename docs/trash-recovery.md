# 回收站与共享材料保护

对应任务：[GitHub #18](https://github.com/xianpingduan/klbook/issues/18)。

## 使用

- 家长进入“错题资料”，打开题目，在“删除资料”中选择“移入回收站”并确认。当前有未保存修改时先保存，避免丢失编辑内容。学习端不增加删除按钮。
- 家长管理侧栏“回收站”（`/admin/trash`）显示原删除时间和到期时间。打开记录可查看题目区、纸质解答、共享阅读材料、备注和学习阶段，再恢复或确认永久删除。
- 恢复保留原收集时间、材料顺序和整理信息，修订号前进。其他设备的旧修改仍需核对，不能覆盖恢复后的版本。
- 保留期限为删除时起 30 × 24 小时。服务启动、运行中的每分钟检查及回收站操作会检查到期记录。停机不承诺准点清理，重启按原到期时间处理。
- 永久删除无法撤销。文件清理失败时记录留在持久清理队列，管理端显示数量和重试入口；服务重启也会继续处理。正在识别的文件在任务结束后再清理。

## 存储与重试

题目软删除使用独立删除记录，正常列表及筛选选项排除这些题目。删除、恢复、永久删除要求有效的设备会话和家长授权，操作带预期修订号与稳定操作 ID。重复删除不延长保留期，同一操作重试返回原回执。

永久删除在短事务中移除题目与关联，留下删除标记和清理意图。检查所有题目（包括回收站和已取消草稿）、题目区、解答区和共享阅读材料的引用后，才清理无引用图片。只处理本次删除涉及的材料，不扫描删除刚上传、尚未关联的独立图片。共享阅读材料仍被其他题目引用时保留；最后一个关联题目永久删除时清理该阅读材料及其独占图片。

操作账本不再外键依赖已删实体，保留原操作 ID、内容摘要与目标 ID，用于阻止迟到的上传/保存重新创建记录。页与阅读材料也保留删除标记。清理识别文本和页引用，但保留调用状态、次数和费用历史；不影响预算核算。文件删除不跨越数据库事务，重启可从清理队列续做。

联网设备读取删除状态后移除正常列表中的已删缓存，保留未提交的编辑记录与本机图片。自动同步跳过已删除题目，其他上传继续。“收集”页展示需要家长处理的本机文字。恢复后可打开题目核对；永久删除后可复制仍保留的本机文字。离线设备在重新联网前可能仍显示旧副本；回收站不等同于跨设备擦除或独立备份。

## API

| 接口 | 权限与用途 |
| --- | --- |
| `GET /api/v1/admin/trash?offset=0` | 家长；每页 50 道及清理状态 |
| `PUT /api/v1/admin/trash/:id` | 家长；`operationId`、`expectedRevision`、`action: trash/restore/purge`，永久删除还需 `confirm: true` |
| `POST /api/v1/admin/trash/cleanup` | 家长；重试清理并返回当前状态 |
| `GET /api/v1/collection/deleted-questions` | 日常会话；仅删除 ID、修订与时间元数据，用于本机补传核对 |

旧题/旧页/旧阅读材料的访问或补传返回 `410`；修订冲突返回 `409`。原操作回执可重复读取，不能以回执推断对象此刻仍处于该状态，应重新读取列表。

## 验证

`test/api/trash.test.ts` 使用真实 SQLite、附件、两会话和可控时间，覆盖共享材料、跨页/答案恢复、原删除时间、停机到期、真实目录故障后重启、旧操作、识别并发与费用历史。

`test/e2e/trash.spec.ts` 使用真实后端，覆盖管理确认、学习端入口、离线文字保留、上传回执丢失后的删除、授权失效、永久删除回执丢失重试。浏览器网络拦截用于构造无法连接/回执丢失，不替代数据库或文件。

实际运行结果和部署检查见 [#18 验证记录](verification/issue-18.md)。
