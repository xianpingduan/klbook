# 本地家庭账号与平台边界

对应 #2，2026-09-20。一个后端实例管理一个家庭资料库、一个学习者和一个家长账号。初始化后 `libraryId`、`learnerId`、`accountId` 不因登录、重启或密码恢复而变化。

## 凭据与权限

- 首次设置需要后端数据目录中的随机设置码，防止网页入口开放时被其他设备先行初始化。设置码仅用于首次建立家庭；数据库唯一约束和事务防止并发建立第二个家庭。
- 密码为 12～128 个字符，保留空格，不做截断。使用 Node `scrypt`，随机 16 字节盐，N=32768、r=8、p=3，32 字节输出；固定参数记录于程序版本。未知账号也执行一次同等开销的校验。依据 [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 和 [Node 24 crypto](https://nodejs.org/docs/latest-v24.x/api/crypto.html#cryptoscryptpassword-salt-keylen-options-callback)。
- 设备令牌、管理令牌、恢复码均使用 32 字节密码学随机数，服务器只保存 SHA-256 摘要。普通设备令牌通过 `Authorization: Bearer …` 传输，不进入 URL。
- 设备会话默认有效 30 天；管理授权有效 5 分钟，另用 `X-Parent-Authorization` 请求头传输并绑定设备。家长输入密码登录设备本身不会获得管理权限。
- 注销/撤销删除对应会话，外键级联清除该设备的管理授权。恢复账号在同一事务中更新密码、轮换恢复码、清除全部旧设备，再签发一个日常设备会话。
- 哈希计算在事务外执行；提交前重新核对密码或恢复码版本，避免并发恢复后仍签发旧凭据的会话。恢复码只能使用一次；已验证家长可补领新码并使旧码失效。
- 初始化、登录、恢复、管理验证分别按实际连接 IP 每分钟最多 10 次，计数保存在 SQLite，重启不会清空。没有信任客户端自报的转发 IP；将来配置反向代理时需同时评估限速规则。
- 所有 API 禁止缓存；拒绝非白名单浏览器 Origin；精确 CORS 允许 Authorization 和家长授权头，不依赖第三方 Cookie。错误响应不回传数据库、密码哈希或堆栈。默认不记录请求体、请求头或令牌。

开发仅使用回环 HTTP。家庭 HTTPS 入口和设备证书由 #4 落实；不要将本机开发 HTTP 配置直接暴露到家庭或公网。

## 数据落地

`family.sqlite` 位于显式配置或用户应用数据目录，附件目录为同级 `attachments`。启用 WAL、外键、FULL 同步和 5 秒 busy timeout；带 `user_version` 的事务迁移拒绝未来版本，失败不重建已有资料。备份完整性和迁移/升级维护由后续对应任务继续落实。

恢复码只在生成响应中显示，设备持久存储不保存恢复码或管理令牌。丢失响应时可用已设置密码登录并补领恢复码。密码与恢复码同时丢失无法绕过鉴权；恢复完整运行备份属于另一个流程。

## API 边界

所有路径以 `/api/v1` 为前缀，响应为 JSON（204 除外）。

| 方法 / 路径 | 身份要求 | 行为 |
| --- | --- | --- |
| GET `/info` | 无 | 仅返回应用身份、API 版本和初始化状态，无家庭姓名 |
| POST `/setup` | 本机设置码 | 初始化并返回日常会话、恢复码 |
| POST `/sessions` | 账号和密码 | 新建当前设备日常会话 |
| GET `/home` | 设备会话 | 真实账号、学习者、资料库和当前设备 |
| DELETE `/sessions/current` | 设备会话 | 注销当前设备 |
| POST `/admin/grants` | 设备会话 + 再次输入密码 | 返回短期管理授权 |
| DELETE `/admin/grants` | 设备会话 + 管理授权 | 结束管理 |
| GET `/admin/devices` | 设备会话 + 管理授权 | 列出未过期设备，不返回任何令牌 |
| DELETE `/admin/devices/:id` | 设备会话 + 管理授权 | 撤销设备，包括当前设备 |
| POST `/admin/recovery-code` | 设备会话 + 管理授权 | 生成替代恢复码并结束当前管理授权 |
| POST `/recovery` | 恢复码、新密码 | 重设密码并注销所有旧设备 |

设备会话缺失、过期或撤销返回 401；普通会话越权或管理授权不匹配/过期返回 403；重复初始化返回 409；输入错误返回 400；超限返回 429。

## 前端边界与后续任务

`ClientPlatform` 定义服务目标配置、设备凭据、按资料库/账号划分的 Blob 暂存、HTTP 传输。`browser-platform.ts` 提供网页适配：来源与配置/凭据保存在浏览器适配内部，Blob 通过 IndexedDB 事务落地。业务页面不读取 `window.location`、localStorage 或 IndexedDB。

`FamilyApi` 固定一次连接的精确目标来源；先无凭据探测，再读取只属于该来源的设备凭据。认证后的首页必须匹配保存的资料库与账号。请求禁止重定向、Cookie、缓存和 URL 凭据，具有超时。管理授权仅保留在界面内存中，刷新或结束管理后不复用。

当前默认连接网页自己的 API；配置读写和暂存适配入口已建立。可视化地址设置/身份确认由 #11/#12、收集草稿与补传队列由 #9/#10 实现；本次没有把适配入口当成这些完整用户流程。原生 App 将替换目标设置、传输、Keychain/Keystore 凭据和原生文件暂存适配，详见 #26。
