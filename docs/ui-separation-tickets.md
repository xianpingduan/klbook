## 技术决定的归属

沿用当前技术栈和数据库、图片、设备凭据/暂存边界。UI-01 在第一个真实访问流程中确定路由、样式隔离和共享状态方案，并记录备选、兼容性及限制。外部供应商和原生平台选择仍归原有能力任务，本轮不重做基础选型。

## 迁移方式

UI-01 先建立可运行的两端入口，尚未迁移的收集和管理能力可在各自入口承接；其余任务逐项替换具体界面并删除对应旧入口。每项都包含真实服务/数据行为及相关验证，不能以单独 CSS、空菜单或只写方案作为完成依据。

必要的 API 与数据库行为优先复用；垂直切分不意味着每项都必须新增表或接口。
