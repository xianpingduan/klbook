审查基线：用户确认的 `c8dc84a`。任务：[GitHub #4](https://github.com/xianpingduan/klbook/issues/4)。

## 实现

- 系统拍照、相册多选和电脑上传使用相同收集流程；每批独立操作标识、整体原子暂存、逐张上传、取消及重开进度。
- 设备暂存格式从单张 v1 升到批量 v2，兼容旧格式读取；按资料库、账号隔离。已有服务端资料与数据库格式不变。
- 现有方向校正、框题、学科确认、已收集找回和原图保留继续复用；新增手机尺寸与 touch pointer 事件验证。
- Caddy 2.11.4 提供只绑定指定私有地址的 HTTPS 代理；后端仍监听回环地址。提供准备、启动、核对身份后停止和限范围防火墙脚本，不自动安装根信任。
- 网关返回 502/504 时明确提示家庭电脑服务不可达；材料可继续重试。

## 已执行的独立检查

- `npm run build`：TypeScript 与前后端构建通过。
- 新增批量浏览器用例：多选三张、取消单张、刷新恢复剩余材料、另一个会话找回；坏图可跳过、拍照选择器取消提示、手机尺寸 pointer 触控框题、方向校验、停止真实后端再恢复。
- 浏览器限制所有非本地请求的流程仍可登录、收集和查阅；这是网络请求约束验证，不等于拔除真实互联网出口。
- 真实 Caddy 探针在独立临时资料库完成严格 TLS 校验，拒绝不受信 CA，验证来源限制、登录、JPEG 原图上传、框题保存、第二设备会话读取及原图字节一致。真实后端停止后网关返回 502。探针 `.scratch/verify-lan-flow.mjs`，日志 `.scratch/issue-4-lan-probe.log`。
- 本机部署入口严格 TLS 请求健康检查 200、合法来源预检 204；题目资料库沿用原目录。Caddy 在 `%LOCALAPPDATA%` 的目录发生 EXDEV；项目独立目录验证可用，没有改变目录加密设置。
