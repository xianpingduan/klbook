# 后台资料整理与来源管理（#31）

实施依据：[任务 #31](https://github.com/xianpingduan/klbook/issues/31)、[独立布局规格](spec-ui-separation.md)。

## 操作路径

- `/admin/materials`：家长验证后进入错题资料。已收集、草稿分别显示真实总数，每页 50 道，继续加载使用原有分页接口。
- 资料表格每行只有“打开”。详情宽屏左侧显示题目与原始页，右侧直接修改学科、来源、页码、题号和备注；窄屏上下排列，表格在自身区域横向滚动。
- 资料页只提供一个“上传材料”入口。上传后在同页框题、确认学科并保存；批次可以继续下一张、取消单张或稍后继续。离开当前编辑前先处理未保存字段。
- `/admin/sources`：新增、改名、停用和启用来源。表单与来源表格独立显示；未保存时先保存或取消当前编辑，再操作其他来源。

## 共用数据与重试

后台与学习端复用题目编辑、原图、批次暂存、修订号和稳定操作标识。资料原图、题目身份和已有收集日期不因家长更正而改变；保存草稿不会算成已收集。当前改造不修改数据库结构、缓存格式或网页来源。

上传前保存原始图片及操作标识；保存失败保留表单。服务器已接收但响应丢失时，使用原操作标识重试，不多建题目或来源。来源重名与旧修订仍由服务器拒绝。刷新来源表格保留当前输入与原修订，不自动覆盖其他设备的修改；发生冲突后可保留输入供核对，取消当前修改后重新打开最新来源。

列表重新进入或刷新时读取服务器。来源改名更新关联题目的显示名称；停用来源不再供新题选择，旧题保留来源且可以修改其他字段。资料保存后，另一学习会话重新进入或刷新即可读取同一份资料。

## 管理验证与离开保护

后台仍使用 5 分钟家长验证。后台资料的读取、上传和保存携带管理授权，服务器同时检查设备会话与该授权；写入前再次检查。普通学习请求仍仅需原有设备会话。来源管理接口一直强制检查管理授权。

管理到期或被撤销后隐藏后台内容，保留当前家庭允许保留的表单与待上传材料。重新验证成功后继续；验证失败不会清空输入。保存离开时若被撤权，关闭离开提示，先完成重新验证，避免弹窗挡住验证表单。

资料和来源表单通过 `useEditorLeave` 接入共同离开保护与对话框。切换页面、结束管理或浏览器后退时，可继续编辑、保存后离开或放弃本次修改。刷新/关闭仍使用浏览器原生提示；未提交字段不承诺刷新恢复，不将密码、管理令牌或恢复码保存为草稿。

## 范围

本项承接既有单页图片采集、资料更正和来源管理。设备与账号页面归 #32；识别服务、备份、回收站、导入导出等仍按原业务任务推进。验证证据见[实施记录](verification/issue-31.md)。
