# 局域网拍照与批量相册采集

对应 [#4](https://github.com/xianpingduan/klbook/issues/4)。电脑仍使用本地页面；同一家庭网络的手机、平板通过电脑的 HTTPS 入口登录同一个家庭资料库。

## 采集

- 提供拍照、相册多选、电脑上传三个入口。一次最多 10 张、总计 75 MB；每张仍限 15 MB、4000 万像素。这是本批暂存的资源上限，可分批继续。
- 先将整批图片和稳定操作标识原子保存到设备暂存，再上传第一张。每张上传后框题、选择学科、保存；详情页选择“继续下一张”。也可以保存草稿后返回列表。
- 待上传列表显示上传与取消数量，允许取消单张。刷新后可以继续剩余材料，已上传草稿在家庭资料库中继续整理。取消只移除本机待上传项；成功上传但响应丢失时，服务器可能已有草稿，取消不删除该草稿。
- 上传失败保留整批未确认的材料，重试沿用操作标识；设备暂存失败时当前页面保留图片，先修复存储再重试。没有成功暂存前关闭页面会丢失内存中的选择。
- JPEG 的 EXIF 方向应用于预览及框题坐标，原始文件字节保持不变。支持 JPEG、PNG、静态 WebP。当前 Windows 编解码器不支持 HEIC/HEIF；请在相册导出 JPEG 后选择，或把相机格式设为兼容格式。选择器实际交付何种格式须真机记录；不假定苹果相册总会转换。
- 拍照使用系统文件选择器的后置相机提示。浏览器可能打开普通选图界面；取消或无法取得照片时提供相册、上传退路。网页不能可靠区分系统选择器中的取消与权限拒绝。此限制和图片格式需要真机核对。[MDN capture](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/capture)

## 准备 HTTPS 入口

1. 从 [Caddy 官方发布](https://github.com/caddyserver/caddy/releases/tag/v2.11.4) 获取 Windows amd64 2.11.4，并用发布页的 SHA-256 核对压缩包。后端继续只监听 `127.0.0.1:8787`；网关只绑定指定私有 IPv4，不暴露数据库或附件目录。
2. 在路由器为电脑保留固定 DHCP 地址，并长期使用相同 HTTPS 地址。网页来源改变会形成新的浏览器存储，旧入口未上传材料需先处理。手机上的 `127.0.0.1` 指向手机自身。
3. 选择独立、可持久保留且支持正常文件重命名的网关目录；目录不支持时 Caddy 可能返回 EXDEV。不要删除该目录中的 CA 状态，否则设备须重新信任证书。
4. 在项目目录执行（地址占位符请替换为电脑实际地址）：

```powershell
$gateway = Join-Path (Get-Location) '.scratch\lan-gateway'
$lanAddress = '<电脑的局域网 IPv4 地址>'
.\scripts\prepare-lan.ps1 -LanAddress $lanAddress -GatewayDir $gateway
$env:KLBOOK_ALLOWED_ORIGINS = "https://${lanAddress}:8443"
# 用这个环境变量启动或重启现有后端，保留原来的 KLBOOK_DATA_DIR。
# 后端已在运行时，先停止其已核实的实例，不要另起第二个占用同端口的实例。
npm start
# 在另一个 PowerShell 中启动网关：
.\scripts\start-lan.ps1 -CaddyExe '<Caddy.exe 的绝对路径>' -GatewayDir $gateway
```

网关使用 `tls internal`，证书可在断开互联网时续签；`skip_install_trust` 明确禁止自动安装系统根信任。证书状态目录只在本机使用，只有导出的 `klbook-root.crt` 公共证书用于设备安装。[Caddy 内部 TLS](https://caddyserver.com/docs/caddyfile/directives/tls)、[根信任设置](https://caddyserver.com/docs/caddyfile/options#skip-install-trust)

5. 在管理员 PowerShell 执行 `scripts/allow-lan-firewall.ps1 -GatewayDir <同一绝对目录>`。规则只允许该网关程序、该网卡、该局域网 IP、TCP 8443 和 LocalSubnet；适用于该网卡被 Windows 标为 Public 的家庭网络。不会修改网络类别或关闭防火墙，不配置路由器端口转发。脚本输出单条规则的撤销命令。
6. 将导出的公共证书送到自己的手机或平板，核对来自这台电脑后安装信任；不要传输 `state` 内的私钥。Android 设置中查找“安装 CA 证书”（位置随系统版本变化）。iPhone/iPad 安装描述文件后，还需在“设置 → 通用 → 关于本机 → 证书信任设置”启用该证书的完全信任。[Apple 官方步骤](https://support.apple.com/en-us/102390)
7. 打开 `https://电脑局域网IP:8443`，确认无证书警告后，用已有家庭账号登录。允许系统需要的本地网络访问。不能通过忽略证书错误作为验收通过。

停止网关：`scripts/stop-lan.ps1 -GatewayDir <同一绝对目录>`。脚本核对进程启动时间、程序和配置后停止，只保留数据与证书；再次运行 start 脚本即可恢复。开机自启由 #22 实施，本任务提供的是可手动启动的稳定入口。

## 真机环境准备记录（2026-09-20）

已恢复后端和 HTTPS 网关，沿用同一资料库和根证书。管理员已执行并回读限范围防火墙规则；严格证书及主机名校验下，HTTPS 健康请求返回 200、合法网页来源预检返回 204。

已提供临时证书准备页，仅开放首页和公共证书下载，不代理 API，也不提供数据目录。API 路径和私钥路径验证返回 404，下载证书与原公共证书字节完全一致。设备使用本地交付的连接地址和证书指纹；公开文档只保留通用配置步骤及验证结果。

Windows PowerShell 5.1 默认读取无 BOM 的 UTF-8 JSON 时会误解中文路径；网关启动、停止及防火墙脚本已显式使用 UTF-8 读取。设备设置路径随品牌和系统不同，Android 可在系统设置中搜索“CA 证书”或“安装证书”。[证书设置说明](https://support.google.com/pixelphone/answer/2844832?hl=en)

设备安装完成后，可按本地维护说明恢复原网关配置、重启网关，并只移除临时准备页的防火墙规则，保留应用访问规则及 CA 状态。本次实际采集反馈见下节。
