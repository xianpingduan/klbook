# 服务用量与预算

任务：[GitHub #17](https://github.com/xianpingduan/klbook/issues/17)。家长入口：`/admin/services/usage`，需要有效设备会话及家长验证。

## 总预算和分类限额

总预算默认每月 **50 元**，按北京时间自然月检查。图片识别、语音转写、AI 学习仍使用各自的次数与费用上限；统一页面显示当前分类限额并提供对应配置入口。分类限额不是独占余额，可以合计高于总预算，但所有新付费尝试仍共同受总预算约束。没有新增第二套分类限额，已有配置继续生效。

保存预算不调用供应商、不修改服务开关、不重算历史费用。预算可设为 0；只阻止需要正数费用预留的新尝试，按已配置零单价的请求仍受原有权限、开关和次数限制。免费包剩余量、有效期与供应商余额不会自动查询，价格应由家长按实际套餐核对。总预算是应用内估算限制，不是供应商账单、采购授权或最终费用承诺。

硬件一次性费用、月度电耗估算及硬件／存储容量说明单独记录，默认未核算，不计入服务额度。这些字段是当前家庭维护记录，不作为所选历史月份的实际支出。

## 计量口径

| 能力 | 可得数据 | 费用估算 |
| --- | --- | --- |
| 图片识别 | 本地尝试次数、结果、耗时；现有百度和讯飞接口不返回账单扣费计量 | 按本次配置的单次估算价；成功保留、明确拒绝释放，无法确定结果时保留预留 |
| 语音转写 | 本地尝试次数、输入音频时长与结果；音频时长不是供应商计费时长 | 按本次配置的单次估算价；处理规则同上 |
| AI 学习 | 供应商返回的有效输入、输出和总 token；不一致或缺失时标为未知 | 按本次模型输入／输出单价估算；发送前保守预留，收到有效计量后更新，缺失时保留预留 |

本地尝试包括主动测试、业务识别和每次自动重试，也可能包括免费鉴权阶段失败；不等同于供应商收费次数。保存配置和被额度拒绝、尚未建立尝试的请求不计数。未返回计量不冒充零用量，AI 合计仅汇总有有效计量的尝试并显示其覆盖次数；次数、秒数与 token 不相加。

按尝试开始时的北京时间月份归属，跨月完成仍更新开始月份。历史价格已体现在各条记录中，修改单价不重算历史。OCR／语音原记录为厘元，统一查询转换为整数微元，与 AI 微元相加；不复制调用记录、不重复记账。界面费用显示六位元小数，单独显示其中在途／待计量预留。明细耗时按保存的开始与结束时刻计算。

## 并发、在途和重试

- 每次新尝试在同一个短 SQLite 事务中检查三类总额并写入所属能力的预留。并发请求不能同时消费同一剩余额度；既有类别额度仍同时检查。
- OCR 可能先等待免费鉴权，再发送付费图片请求。发送前会重新核对已修改的总预算；使用已有预留检查，不重复加算，未发出时释放预留。
- 自动重试逐次检查最新总预算、原有权限与能力配置。调低预算可停止未发出的尝试，不把已发送请求改成取消；迟到结果仍按实际返回结算。
- 预留保存在已有调用表中，重启不清零、不重发；服务中断沿用原有的不确定状态。供应商异常计量可能让最终估算高于预留，已发出的请求如实记录，后续正价请求会被拦截。
- 预算不足不影响手动框题、保存、查看及已有资料操作。调整预算或重新启用服务不会扫描或补做历史材料。

## 页面和权限

月度汇总读取整月全部记录，明细每页 40 条，可按月份、能力筛选；明细筛选不会改变全月分类与合计。合并显示成功、失败、不确定、处理中、费用来源、耗时与安全错误摘要，并显示所选月份最近 30 条配置／测试操作。统一接口不返回凭据、鉴权头、原始供应商错误、学习材料或 AI 测试文字。

预算保存有修订号、稳定操作 ID 和账号范围；丢失回执后重放不重复保存，冲突不覆盖其他页面。未保存修改受离开提醒保护，管理到期后保留表单，重新验证才可读写。新数据库迁移只增加预算表与三个现有调用表的联合查询视图，不改写旧题、原图或历史费用。

## API

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/admin/service-usage?month=2026-10&capability=ai&offset=0` | 参数均可省略；返回当前预算、分类限额、全月汇总、明细及审计 |
| `PUT /api/v1/admin/service-usage` | `operationId`、`expectedRevision`、`config`；保存总预算及单独成本记录，不发起服务调用 |

## 供应商核对与真实验收

2026-10-19 核对官方字段：[百度文档分析返回说明](https://ai.baidu.com/ai-doc/OCR/jk9m7mj1l)、[讯飞通用文字识别返回结果](https://www.xfyun.cn/doc/words/universal_character_recognition/API.html)、[讯飞语音听写返回参数](https://www.xfyun.cn/doc/asr/voicedictation/API.html)、[讯飞星火 HTTP usage](https://www.xfyun.cn/doc/spark/HTTP调用文档.html)。前两类当前协议没有账单扣费字段；AI 提供 token 用量。未使用识别字符数、返回段落数或音频端点帧作为供应商计费依据。

自动化以隔离的真实数据库和文件生成跨类记录，只替换外部 HTTP／WebSocket。用户尚未开通语音和 AI，未新增真实调用，也未进入供应商账号查看账单。#15、#16 的真实样例与本任务的真实账单核对仍单独保留，不能由模拟结果代替。

开通后用明确短样例核对：发送前后分类与总额变化、失败／重试次数、控制台可得计量或账单。记录套餐单价、免费包口径和取整规则；不要把密钥贴到聊天或 GitHub。原有讯飞 OCR 成功样例可作为识别适配证据，不能证明另外两类或三类合计已实测。
