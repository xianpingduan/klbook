# 简化收集与选图纠错

用户于 2026-10-08 确认。关联 #4、#14；已收集资料的回收站仍由 #18 实施。

- 保持选图 → 框题 → 下一步选学科 → 保存，不增加预览或确认页面。
- 框题页原地换图；取消系统选图或上传失败不替换当前材料。换图清除该题目区的旧范围和识别引用，保留其他填写信息、跨页顺序与原文件。重试使用稳定操作 ID。
- 未收集草稿可“取消本次”，从正常列表移走，提供撤销；取消保留材料，不物理删除。已收集题目不能走这个入口。并发旧编辑不能复活已取消草稿。撤销入口仅在有已取消草稿时出现，刷新后仍可用。
- 上传不自动识别。已有“下一步”触发所选题目区的后台识别；启停、额度与权限沿用后台配置。重复点击相同范围不重复调用，主动重新识别另计一次。
- 识别区默认折叠；下一步和保存均不等待供应商。结果不自动覆盖用户的范围、文字或学科，可稍后展开查看。保留批次与输入范围，跨页或改框后不展示成当前范围的结果。
- 识别副本使用正向图片并裁出所选区域；原图不改动。照片优先 JPEG 以减少无谓缩小。
- 同步修复此前纸质材料诊断确认的应用问题：讯飞局部行异常时保留有效行，明示部分识别且不自动重试；页面级错误或全部无效仍失败。无题号时仅保留文字，不把每一行当作候选题；学年日期不作为数学依据。这些改动不声称提高了供应商本身的准确率。
