# 学习端收集与续接（#30）

实施依据：[任务 #30](https://github.com/xianpingduan/klbook/issues/30)、[独立布局规格](spec-ui-separation.md)。

## 固定操作路径

- **首页**：固定鼓励语及已收集题目；超过一页继续加载。空库提示使用底部收集入口。
- **收集**：触控设备提供拍照、相册；电脑提供一个选图入口。按输入能力而非屏幕宽度选择入口，不改变学习者身份。支持原有格式与批次限制。
- **我的**：真实连接检查、资料库身份、家长管理与退出。
- **整理题目**：先框题，再确认学科及选填来源、页码、题号、备注。编辑和详情收起 Tab。保存后可以查看原始页、更正信息；未处理完的批次提供继续下一张、取消单张、稍后继续。

## 材料与失败状态

收集页分开显示本机待上传图片和家庭电脑已保存的草稿。设备暂存独立于服务器列表读取，服务器失败不隐藏本机材料，也不把读取失败显示成空库。相机取消或不返回照片时提示使用相册；网页不能可靠区分系统相机未打开和权限被拒绝。

沿用现有 `CaptureCache` 的批次结构及资料库/账号作用域。先持久保存原图片和操作标识，再上传；上传响应丢失或暂存进度写入失败时，用同一个操作标识重试。取消本机材料只移除本机批次项，已接收的服务器草稿仍保留。未确认的上传不标成已同步。

列表读取和写入使用各自的忙碌状态；上传、保存、更正、取消后更新列表。题目打开时重新读取最新修订。旧工作区卸载后，不再继续发起上传或处理会话失效回调；新会话从所属资料库的暂存作用域读取。

## 离开保护

路由边界提供待执行的离开动作，由编辑器决定继续编辑、保存后离开或放弃本次修改。草稿的“保存后离开”保存为草稿；已收集题保持收集状态和原收集时间。校验或写入失败在原编辑上下文显示错误，稳定保存操作标识继续用于重试。

管理验证到期时，编辑区域隐藏并保留输入；离开提示仍在可见的应用外框中。重新验证前禁用保存，继续编辑后可重新验证找回输入，明确放弃也不会删除题目。题目范围共用前后端领域校验，避免边缘坐标的浮点容差不一致。

应用历史条目记录站内路径、历史栈标识及序号。浏览器后退遇到未保存修改时，先恢复编辑条目再询问；继续编辑保留前进/后退历史，批准离开后才执行原历史移动。升级前无标记的历史条目采用恢复当前编辑页的兼容回退，优先保留输入，不能保证保留旧版所有前进条目。

刷新和关闭使用浏览器原生离开提示；只保证已持久保存的图片、批次与草稿能恢复。完整离线重开仍归 #9。这里不引入新的数据库表、缓存命名空间、服务地址或外部能力。

## 范围

学习端和后台复用编辑、原图、批次及保存逻辑，避免出现两套持久化行为。后台现有资料界面仍是中间版本，表格整理归 #31，设备与账号界面归 #32。验证和新版真机清单见[验证记录](verification/issue-30.md)。
