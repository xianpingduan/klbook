# 识别辅助收集

任务：[GitHub #14](https://github.com/xianpingduan/klbook/issues/14)。关联 [#13](https://github.com/xianpingduan/klbook/issues/13) 的业务调用启停及额度验证。

## 使用流程

家长在图片识别后台配置并启用供应商后，新上传到收集入口的图片先完整保存原图和草稿，再尝试识别；服务未配置、停用、额度不足、识别失败或暂时忙碌均不妨碍手动框题和保存。追加跨页图片或已保存历史页可在对应题目区主动选择“识别此页”，不会在浏览、重新启用服务或重启后自动扫描历史。

框题页面显示候选文字组。点选并确认后，把建议范围、文字及可得学科／题号带入当前题目区；孩子仍需检查完整题干与图形、调整或重新框选，再确认学科并保存。其他候选不会自动成为错题，可通过已有“从此原始页再收集一道”继续选择。多个区域仍属于同一题的规则不变。

题干文字选填，可以更正或留空。每个题目区独立保存文字及采用的识别批次／候选引用；原始识别文字和位置不随更正改写。题目详情可展开“查看采用时的识别结果”对照。重新识别产生新批次，迟到结果和新批次均只供查看，须再次明确采用才替换当前内容。

## 能力边界

- 百度沿用试卷分析与识别参数，可按家长配置返回文字和 LaTeX 公式；讯飞通用文字识别支持文字与位置，未接入专用复杂公式识别。页面按当前供应商说明限制，复杂公式、图形、手写与批改以原图为准。
- 候选范围来自文字位置与数字题号的保守分组，学科来自明确的学科名称／词语建议；不是供应商自动切题或错题判断。没有可靠位置时仅展示文字，允许手工框选。多栏、阅读小题、密集排版及图形附近的范围尤其需要人工检查。
- 不承诺候选完整、统一准确率或固定耗时。四科真实纸质材料及手机触控须单独实测；后台合成样例成功不能代替这些结果。

## 保存、重试与费用

每次识别使用持久运行 ID，绑定家庭、页和发起时供应商配置；同一 ID 重发读取原结果，不再次调用。新上传页的初次识别机会只处理一次，上传响应丢失后的重传不会重新计费；当时停用或失败的材料只在用户主动重试后处理。队列最多同时保留 10 个待处理任务，依次执行，超出时可手动收集并稍后重试。

学习端每次新业务调用、排队后开始和自动重试前，均核对登录、启用状态、配置修订、次数及预算；配置切换或停用阻止后续发送／重试，已发出成功结果仍保留。后台家长样例测试有停用豁免，学习端没有该豁免。两种调用与两家供应商共用 OCR 月度计量，后台可查看记录。估算仍不等于供应商账单。

原图的字节与哈希不变；仅在调用前生成遵守 EXIF 方向的 PNG 副本，长边不超过 2800 像素，必要时缩小以满足 base64 后 4MB 的共同限制。记录副本宽高，识别坐标按副本宽高换算为原始页的归一范围；不以屏幕尺寸推算坐标。

数据库 schema 12 为每次页面识别增加页归属、输入尺寸及候选，为题目区增加更正文字和采用引用；旧题目默认空文字、无引用。已有百度／讯飞密文及配套密钥不变。重启只将未完成任务标为中断，不自动重发。

## 验证

采用已确认的公开 HTTP、真实 SQLite 与附件、完整浏览器操作，只在供应商 HTTP 处提供可控响应。覆盖原图不变、停用／额度拦截、后台与学习端用量、幂等、跨设备结果、采用与更正、迟到结果、跨页错误引用、设备撤销、方向及重启。最终执行结果与真实设备清单见[验收记录](verification/issue-14.md)。
