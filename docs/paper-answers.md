# 纸质答案与解答区

对应 [#7](https://github.com/xianpingduan/klbook/issues/7)。答案选填，不改变题目能否完成收集；保留真实原图及其中的手写、批改和图形，不自动去笔迹、生成答案或判定对错。

## 使用方式

1. 学习端打开错题详情，选择“补充纸质答案”；管理端在题目整理页使用同一入口。有答案时入口为“整理纸质答案”。未保存的题目修改先由离开保护处理；同页新题先保存再补答案。
2. 从本题原始页框选答案，也可选择一张答案图片；触摸设备另提供“拍摄答案”，电脑仅显示选图入口。“从已有答案页选择”可复用其他题正在引用的同一页图片。题目及共享阅读材料所用的原始页都可作为本题框选来源。
3. 框住与当前小题对应的纸质答案或批改，支持同页补充多个区域、跨页、重画和排序。每次追加一张，保存后可继续；每题最多 50 个解答区。所有保留的区域必须框选完整，未框选时可移除再保存。
4. “保存答案并返回”只更新当前题目的解答区，不修改题目范围、学科、来源、备注或收集日期。详情中的纸质答案默认收起；展开后可查看。完整原图通过“查看原始页”追溯，包括题目、答案和阅读材料的所有原始页，同图只显示一次。
5. 移除全部解答区再保存，只解除当前题的答案关联。其他题的解答区和原始页文件保留，不会复制、覆盖或删除其他题目的答案。

## 失败保护与暂存

- 选择答案图片使用现有实际附件上传和设备暂存，按网页来源、资料库、账号和题目身份隔离。上传失败或响应丢失后，可在同一题的答案编辑页继续；刷新需要重新打开该题，后台需重新验证家长身份。未提交的框选范围不承诺关闭页面后自动恢复。
- 保存失败保留当前解答区。重试先重放未确认的原操作，再提交随后修改的范围；同一题的答案拥有稳定区域 ID，不因重试重复关联。
- 答案更正与题目共用修订号，两个设备同时修改时返回冲突；已有输入保持在原页面，由用户返回列表重开核对。管理授权失效时重新验证可继续保存。
- 追加图片与答案关联分开保存。上传成功后才会出现可框选的页；保存关联后清理该追加任务。放弃、移除区域或解除引用不删除已上传原图，未完成追加仍可续接。
- 图片限制沿用现有采集规则：JPEG、PNG、静态 WebP，每张不超过 15 MB、4000 万像素。

## 数据与接口

结构版本 8 新增有序 `answerParts`：每个解答区属于一题，引用稳定的原始页 ID。同一页可由多题引用，各题的范围与顺序独立。旧题升级后答案为空；普通题目保存及旧操作重试不清空答案。

- `PUT /api/v1/collection/questions/:id/answers`：`operationId`、`expectedRevision`、有序 `parts`（`id/pageId/region`）；空数组解除所有答案关联。沿用真实设备会话和管理二次验证，校验附件完整性后提交，并核验重放实际返回的快照附件。
- 题目详情及列表返回 `answerParts`。普通题目保存、最初上传与建题请求的重放也检查返回快照中的关联答案附件，不能将缺失附件报为完整同步。
- `GET /api/v1/collection/answer-pages?offset=0`：分页读取当前被解答区引用的原始页，按页 ID 去重、每页 50 个。解除最后一个引用后，该页不再出现在此选择列表，文件保留。

回收站（#18）、导出/导入（#19—#21）与备份（#23—#24）应沿题目→解答区→原始页保留稳定身份、范围、顺序和共享文件关系。永久删除前检查题目区、解答区和共享阅读材料的全部有效引用；不能只检查当前题。本任务不实现自动清理或永久删除。
