## 建议细拆的端到端方向

以下是后续拆分方向，不是已批准发布的新任务清单，也未增加新的 GitHub issues：

- Android App 配置家庭服务、登录、采集一道题并由电脑找回。
- iOS App 完成同样流程，记录实际权限、证书及系统差异；在 macOS 环境可用时尽早验证。
- 已暂存材料在 App 重启后保留、前台恢复补传，并正确处理服务切换和设备撤销。
- App 完成复杂材料收集、家长导出和系统文件导入，与网页资料逐项一致。
- 正式签名 APK 安装及覆盖升级，保留资料、设置并核对兼容性。
- iOS 测试分发、审核可访问的完整流程与最终商店分发；将构建成功、TestFlight 和正式可下载分别验收。

拆分时以现有能力为前置，例如最小移动采集依赖已可用的登录/保存/服务配置；完整离线依赖 #9/#12 行为；资料包流转依赖 #19—#21。具体边必须逐项核对，不能把所有移动工作统一设为等 #25 完成，也不能让缺少 Mac 阻止当前网页开发。

当前应继续 #2 的家庭登录与平台边界；补充移动规格和细拆 #26 可以另行推进。既有 24 项无需重新发布，移动里程碑仍保持待分诊，不能因文档补齐而标记业务验收完成。
